# 栖卷 Windows 0.8.23

0.8.23 修正缓存设置对话框的按钮顺序与裁切，并让全局“主按钮右置”在菜单打开的对话框上也可靠生效。

## 本版完成

- 缓存与存储对话框改为内容自带操作栏：“关闭”在左（次级）、“保存”在右（主按钮）；实测点击保存成功并显示“存储设置已保存。”。
- 内容滚动区限高 400，底部操作栏不再被对话框下边缘裁切。
- `DialogOrdering` 在 `Opened` 后若按钮尚未生成会延迟重试：修复“缓存与存储”这类从菜单打开、首帧找不到按钮导致主按钮仍在左侧的问题。
- 下拉的焦点框保留系统焦点指示（尝试改细后无效，回退，避免降低键盘可访问性）。
