# 栖卷 Windows 0.8.85

0.8.85 重做批量下载确认框的信息层级与弹层遮挡：确认清单改为“名称 · 大小”主信息 + 目标路径次级信息，按“将添加/未添加”分组，滚动高度接入弹窗自适应规则，打开确认框时收起“正在核对下载目标”浮条。

## 本版完成

- 清单项从单个 12px 纯文本块拆成两层：`名称 · 大小` 13px 主色，目标路径 12px 次级色（可选中复制）；长路径可换行。
- 增加“将添加 N 项”“未添加 N 项”分组标题；失败/跳过项使用次级色并单独成组，不再与可下载文件混在同一层。
- “枚举达到上限”“部分条目未完成预检”“其余 N 个文件略”等提示统一 12px 次级色。
- 滚动区 `MaxHeight` 从固定 400 DIP 改为 `DialogOrdering.ContentMaxHeight(this, 400)`（窗口高度 − 240，上限 400）；打开确认框时显式收起下载冲条，`RenderDownloadNotice` 在下载对话框打开期间不再重新弹出，避免“正在核对下载目标”盖在模态框后。
- 实拍复核 1800×1250 与 1200×900：标题、说明、分组、4 条清单与底部主/次按钮完整显示，无裁切；使用测试服务器真实选中 4 张图片触发，取消后未提交任何下载。
