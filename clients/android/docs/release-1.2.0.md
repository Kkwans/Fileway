# 栖卷 · Fileway Android 1.2.0

## 压缩包浏览

- 重整文件列表、搜索和路径导航。移除重复摘要、常驻解压表单与横屏固定列表高度，让浏览内容成为主体。
- 包内条目单击查看详情、长按多选，双击进入文件夹或打开支持预览的文件；选中使用蓝色边框和背景，取消继承选中的子项时保留其他选择。
- 多选入口在顶部原位切换，保留刷新与更多操作；支持当前结果全选、反选。完整目录按目录路径选中，保留 500 个独立选择的安全限制。
- 解压目标及确认操作移入共享弹层；目录选择、详情和结果操作采用统一按钮。取消普通解压确认后清除临时选择。
- 保留权限校验、原始路径身份、截断禁用、危险条目阻止、同名跳过、未知提交结果核对及取消保护。

## 界面统一

- 二级标题栏避让横向切口；共享贴底弹层延伸至手势导航区域，按钮保留安全距离，独立窗口适配系统栏与主题。
- 压缩包和复制／移动目标使用共享圆角目录行，取消默认不透明列表块，统一动作布局。
- 图片缓存图库进入多选后保留排序入口，退出保持原位，使用独立全选／反选图标。
- 调整音频播放页的标题、文件信息、进度和控制区；移除音频及许可证面板重复的底部关闭操作。
- 视频信息卡片时长采用 `1h 23m 45s`、`23m 45s`、`45s`，保留秒精度；播放进度条格式保持不变。

## 安装与验证范围

- 正式版 **1.2.0 / versionCode 44**；Android 10及以上，包含 arm64-v8a、x86_64。
- 原包名、签名、本机数据、服务端 API 和数据库结构保持一致，可直接覆盖安装。
- 压缩包路径和选择规则的 8 项定向测试通过；1.2.0 候选在小米 14 上检查了真实压缩包的浅深色浏览、详情、多选及目标目录面板，未提交真实解压。
- 一项设备自动化用例在测试生命周期中阻塞，未计为通过；后续 lint 分析也出现 Kotlin 类型解析耗时异常。共享界面已有通过的 lint 结果，最终小修按影响范围复用；不宣称完整自动化或最终源码全量 lint 已通过。
- 正式包按本轮授权直接发布，不追加手机验收。此前已注明的特定杜比片源色彩波动尚未确认解决。
