# 栖卷 Windows 0.3.0

本版以用户要求的播放器与文件浏览交互修正为主，保留已认可的 Screenbox 播放外观。
Windows 11 x64 自包含、未签名本地预览；不创建 GitHub Release，不安装或启动应用。
本批由用户人工验收，开发只执行必要构建与打包，不运行测试、不新增测试代码。

## 播放器

- 视频所属窗口独占真实 FullScreen Presenter，控制窗口按实际物理像素跟随，
  使用 AppWindow 同步 XAML 内容尺寸，避免控件停留在进入全屏前的窗口大小。
- 窗口模式下标题空白处拖动、四边和四角缩放转交所属视频窗口的原生移动/缩放流程；
  同时覆盖 XAML 和 HWND 输入路径，提供对应方向光标，不移动视频子窗口或控制浮层本身。
- 跳转后保持用户的待确认目标，直到播放器确认接近目标、报告错误或超时；旧播放快照
  不再立即把进度圆点和时间文字拉回旧位置。该显示目标不会当作观看记录写回服务器。
- 播放和暂停状态默认都在 5 秒无操作后隐藏控件，键盘操作重新显示，菜单打开时保留。
  “更多 → 控件与提示”或主窗口“工具 → 交互偏好”可调节隐藏及提示时长（2—30 秒）。
- 字幕位置、字号、大小比例改为滑动条，即时发送并合并连续调整；延迟和字体选择也即时生效，
  无需应用按钮。字体列表后台枚举系统已安装字体，显示偏好保存在当前 Windows 用户设置中。
- “使用上下黑边放置字幕”默认启用，坐标按整个窗口计算：滑动条仍为 0—100%，但 100%
  指窗口底部，不是视频画面底部，因此能够进入视频画面以外的上下黑边，不通过越界数值裁切字幕。
- 默认普通文本字幕维持 `sans-serif`、字号 38、比例 1.0、位置 95%；字号是 mpv 在参考画面高度下
  的渲染单位，不是固定的 Windows 点数。来源为 [mpv 0.41.0 字幕默认值](https://github.com/mpv-player/mpv/blob/v0.41.0/sub/osd.c)。
  ASS/SSA 即使没有特效，也可能自带字体、字号和位置，默认保留；取消“保留 ASS 原始排版”后才开放覆盖。
  PGS 等图像字幕不提供无效的字体/字号控件。SRT 也可能带少量行内样式；不能仅凭截图确定影片使用了哪种字体。
- 播放表面的普通光标显式恢复为箭头，避免沿用系统临时忙碌状态；这不构成性能、全屏或退出问题已完成实机验收的证明。

## 文件浏览与提示

- 文件夹、普通文件、文本、图片、视频、音频和代码采用微软 Fluent UI System Icons 的原始彩色 SVG。
  保留列表/网格缩略图替换逻辑、主题和已调整的网格居中；不自行重绘替代图标。
  资源版本和 MIT 许可证随应用分发，见 [图标来源](../licenses/fluent-file-icons.md)。
- 修正顶栏菜单高度和默认外边距组合造成的文字裁切；菜单仍按文件操作、选择、视图、工具组织。
  目录面包屑保留在内容导航行，采用更轻的圆角表面；导航和内容保持对称内边距。
- 布局选择直接显示当前布局，与类型筛选统一为下拉浮层；选中项整行区分，不占单选圆点列。
  类型可连续多选，面板不会每选一次就关闭；当前进程内按账号和目录保留组合，重启后仍沿用
  旧数据库支持的单一主类型，多选组合的跨重启持久化尚未扩展。
- 详细信息改为独立、可关闭的模糊材质弹窗，复用播放器设置窗口的 Thin Desktop Acrylic，
  跟随主窗口明暗模式；文件区不再预留侧面详情宽度。
- 普通操作、上传/下载阶段和记录提示移到不占列表行高的浮层，默认 5 秒关闭并可手动关闭。
  下载进度快照只更新已有内容，同任务同阶段不会反复弹出；操作结果和任务状态仍保留在原有记录中。
- 区分文件和空白区域的右键菜单；文件菜单保留针对所选资源的操作，空白处提供新建、上传、
  粘贴、刷新和视图。可选中文本使用原生文本复制，不再当成复制远端文件处理。
- 侧栏滚动区增加独立的滚动指示预留，使用原生自动滚动条策略；“NAS 文件任务”统一改名“文件任务”。
  文件任务仍表示服务器执行的复制/移动等操作，不是服务器网页。

## 版本与边界

可靠目录/批量传输、续传和重启恢复没有因本版提高版本号而算作完成，顺延至 0.3.1；
完整边下边播范围顺延至 0.3.2。范围及依赖见 [产品路线](product-roadmap.md)。

旧播放器退出 CFG 崩溃仍未完成根因闭环，不能把本批正常编译视为修复。
全屏错误帧、实际拖动/缩放、字幕黑边位置、字形、系统缩放及流畅度由用户实机验收；
本批没有操作私人媒体、运行测试、修改生产服务或改动 Android。
