# 栖卷 Windows 0.8.166

本版处理文件任务页与操作记录页的列对齐。两页共用同一个列头（“任务/操作”标题 + “创建时间/时间”），
但操作记录行模板没有图标列和行内边距，导致列头标题相对行内容左移 36 DIP 左右。

## 现状取证

- `NasTasksControl.xaml` 的 `ListHeaders` 使用 `Padding=18,0,18,6`、标题 `Margin=36`，
  按“图标 24 + 间距 12”给任务行留位。
- `TaskRecords` 行有 24px 图标列、`Padding=8`，加 `ListViewItem Padding=10` 后名称左缘是 54。
- `OperationRecords` 行没有图标列、没有 `Padding=8`，名称左缘只有约 22；与共享列头“操作”错位。
- 操作记录与任务记录原本是两套行定义，尺寸很容易漂移。

## 改了什么

1. `NasTaskOperationRow` 增加 `IconName`：复制/移动/取消/重试/取消归档分别映射
   `copy`/`scissors`/`x`/`arrows-clockwise`/`arrow-counter-clockwise`，其余用 `clipboard`。
2. 操作记录行模板补 24px 图标列与 `Padding=8`，与任务行使用同一几何：图标 20、
   名称列 `*`、时间列 `Auto`、列间距 12。
3. 列头“操作”与操作行名称左缘因此同为 54；时间列右缘保持共享列头对齐。
4. 版本号 `0.8.166` / `FileVersion 0.8.166.0`。
