# 栖卷 Windows 0.3.7

边下边播与历史重开里程碑；本地未签名预览，供用户人工安装验收。

## 本版新增

- **历史完成下载只读重开**：传输详情的播放按钮对已完成且发布校验一致的任务开放。
  打开时先走活动执行读取；无活动执行即自动转入只读重开——核实终态记录（Completed、
  发布身份、LocalSha256==ServerSha256、确认偏移等于总长、无不确定性）后，以既有
  OpenOwnedAsync 的发布分支按 128 位文件身份只读重开最终文件，长度与发布身份一致
  才授予读取租约，重读记录未被并发修改才返回。不产生任何写入、删除或远端能力；
  读取器纳入既有账号/权限/排空撤销集合。
- **续传执行期间的边下边播**：续传执行截断到确认偏移后即恢复读取准入（可读前缀=
  已确认内容），与 fresh 执行一致地提供前缀读取与认证远端 Range 补齐；不授予
  写入/删除权限，发布语义不变。
- 至此 0.3.5—0.3.7 的下载/播放连续生命周期闭环：fresh 下载边下边播、暂停/续传
  期间边下边播、崩溃/退出后重启恢复并继续边下边播、完成后从传输列表重新播放。

## 边界

- 历史重开要求终态证据完整（缺哈希、有不确定性或记录被并发修改即拒绝），不只是
  放开按钮；旧端未完成校验的任务不能重开。
- 归档导出（0.3.6）仍不可播放（动态 ZIP 不是媒体）。
- 普通/尾置 MP4、MKV、大跨度跳转与多容器真实旅程由用户人工验收；一次通过不外推。

## 验证口径

Release/x64 构建零警告零错误；切片提交 `c6fb48d9`、`02c8f80d` 均已推送。
