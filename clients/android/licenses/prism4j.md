The bundled LICENSE is byte-for-byte upstream. There is no upstream separate
NOTICE; prism4j-NOTICES.txt identifies retained distribution attribution.
Deliver these two TXT files through the existing Android assets/licenses route.

The bundler supplies 25 real canonical grammars: brainfuck, c, clike, clojure, cpp,
csharp, css, css-extras, dart, git, go, groovy, java, javascript, json, kotlin,
latex, makefile, markdown, markup, python, scala, sql, swift, yaml. Markup aliases
include XML/HTML/MathML/SVG. Original source is generated by the official processor;
Fileway only traverses token nodes to attach Compose spans. Missing Rust, Ruby,
Shell, Perl, PHP, CoffeeScript, TypeScript use the separate fixed Highlights1.0.0
engine (see highlights.md), with no guessed grammar substitution.

Core base classes are major51/Java7; bundler major52/Java8. This is not proof of
Android/Gradle compatibility. In particular, the fixed bundler uses build-only
google-java-format1.6 with javac internals; JDK17 annotation processing needs an
actual Gradle gate. No global JDK, JVM exports, KAPT or environment change is made.
