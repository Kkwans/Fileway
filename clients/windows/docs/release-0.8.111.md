# 栖卷 Windows 0.8.111

0.8.111 收敛文件任务与传输中心的完成态排版：任务详情不再显示满格蓝色进度长线，传输中心已完成记录隐藏进度条与无效的暂停按钮；文件任务去掉空提示行的双倍间距，未选中任务时“更多任务操作”不再呈现为可用。

## 本版完成

- 文件任务：错误提示从独立 Grid 行移入筛选组下方的 `NoticePanel`，无提示且无需核实说明时整体折叠，列表列头上移约 12 DIP；`更多任务操作` 按钮在未选中任务时禁用，与刷新详情/请求取消/重试一致。
- 任务详情：进度条改放在 6 DIP 圆角中性轨道内（4 DIP 指示条），完成度 100% 的已完成任务隐藏进度条，不再出现横贯详情区的蓝色长线；进行中/部分完成仍显示。
- 传输中心：已完成下载/上传记录隐藏进度条，只保留文件名、字节、耗时与路径；不可暂停/继续的任务隐藏暂停按钮，只保留删除。批次头在全部完成后同样隐藏总进度条，任务详情内嵌套进度条同步。
- 真实数据：文件任务 7 条服务器任务、传输中心 4 条历史下载记录（含等待确认、已完成）实拍；任务详情选中→返回列表。
- 证据：修复前 `20261031-ui08111/screens/tasks.png`、`tasks-detail.png`、`transfer.png`；修复后 `screens/final/tasks.png`、`tasks-detail.png`、`transfer.png`。
