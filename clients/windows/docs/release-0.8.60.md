# 栖卷 Windows 0.8.60

0.8.60 把「工具 → 打开方式」的 7 个类别改为双栏分组，减少竖向滚动，并让两列 ChoiceBox 等宽对齐。

## 本版完成

- 打开方式对话框：Markdown、文本/代码、图片、视频在左列；音频、PDF、压缩包在右列。
- 说明文案保持在双栏上方；两列使用相同星号宽度，下拉框与标签左右对齐。
- 7 个类别在默认对话框高度内一次可见，不再需要在长列表中滚动。
- 保存/取消按钮顺序与样式保持不变。
