# 栖卷 Windows 0.8.30

0.8.30 让传输中心把同一次文件夹上传显示为一个批次，而不是一长串互不关联的文件行。

## 本版完成

- `UploadItem` 投影携带 `UploadBatchInfo`；上传任务从持久化计划读出批次身份，历史记录与新事件都能带上批次信息。
- 传输中心上传页按批次成组：
  - 批次卡片使用文件夹图标底、批次名、聚合进度条、“x/y 已完成”、文件数与总大小；异常项单独计数提示。
  - 组内文件行左缩进 24px，仍可点开单个任务详情；批次行不承载暂停/删除操作。
  - 上传页的“已显示 N 条记录”只统计真实任务，不把批次汇总行算作记录。
- 下载页模板与交互保持不变。
