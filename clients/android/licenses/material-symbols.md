# Material Symbols Rounded

Google Material Symbols Rounded, Apache License 2.0. Fixed source commit: [`49d4db35df873165d6bd6ba09b063c7dafbac2f4`](https://github.com/google/material-design-icons/tree/49d4db35df873165d6bd6ba09b063c7dafbac2f4).

The local Android VectorDrawable subset uses weight **400**, grade **0**, optical size **24**, and **FILL 0** for ordinary controls. Only the four `_filled` navigation resources use **FILL 1**. The upstream default `*_24px.xml` exports encode weight 400 and grade 0; variants spell out other values.

The upstream path geometry, 960-unit viewport and 24dp intrinsic size are preserved. The theme-dependent `android:tint` attribute is removed because Compose supplies semantic tint. Directional back/forward/move/logout resources enable Android auto-mirroring; other resources do not. Formatting and source comments are updated. Resource names remain stable for existing callers, including the historical `art_` names, which now refer to Google geometry.

The full Apache 2.0 license is retained in `material-icons-APACHE-2.0.txt` and in the APK at `assets/licenses/material-icons-APACHE-2.0.txt`. Original Material Icons launcher artwork and the ArtPlayer MIT license/design adaptation notices remain retained; this replacement does not erase their attribution.

File-type resources describe the type only; ambiguous code/configuration/unknown files must retain a visible extension or short type label in the interface. `ic_verify` uses `fact_check` for checksum verification; `ic_info` remains an information/details action. `ic_restore` is restore-from-trash, distinct from history.
