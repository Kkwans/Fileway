# 栖卷 Windows 0.9.0

Windows x64 未签名正式包，已更新本地服务端和播放器。构建源码为 `2a3dcb836e64fa2b99202e7e605c7504fd44f339`，程序集文件版本为 `0.9.0.0`。

## 改动

- 增加应用更新检查和本机缓存图库，补齐服务器全局设置、分享与用户管理、文件夹统计以及内嵌 Tailscale 连接流程。
- 统一页头、空态、资源行、分段选择和通知，复用主题色、图标和焦点样式。设置适配宽窄窗，更新检查、图库刷新和存储分析主操作与对应内容同行。
- 文件搜索使用顶部浮层，输入筛选当前列表，按 Enter 搜索当前目录及子目录。路径栏可点击空白处进入编辑，显示可读的中英文目录名。最近访问保留原文件失效状态，文件恢复后可从同一条记录打开。无界网格显示完整文件名，详细卡片的类型、大小和日期跨列对齐。
- 短反馈固定在标题栏中央，保留操作入口和自动消失。放大系统文字时，传输中心保留记录状态与动作。弹窗和浮层提供实色、柔和模糊和高级毛玻璃。本版修复工具菜单透字，确认实际系统背景生效后才应用半透明色调，系统限制时使用主题实色。
- 图片查看器使用自绘标题栏、动态取色、顶部工具和可调缩略图，支持滚轮缩放与键盘换图。Markdown 支持渲染态编辑及外部软件打开，代码预览支持语法着色与可选行号。ZIP 列表、表头及结果共用边界，解压结果紧接短列表。
- 文件夹上传保留目录层级，传输记录保留同名保护、断线续传和实际任务详情。播放器复验暂停后下一段、音频跳过、末段动作及全屏往返。
- 合并 Windows 分支与主线服务端、共享核心，保留主线账号会话状态和 Windows 的缓存、条件下载、搜索路径能力。兼容画质调用统一到合并后的 HLS 任务接口。
- 修复本地服务端停止与重启、不同端口的服务误阻止部署，以及部署表单意外提交账号的问题。新部署允许至少六位密码；不自动修改已有账号或密码。
- 修复播放器按住标题区域拖动、进度悬停时间和雪碧图裁切，并补充跳转结束后的控件自动隐藏状态衔接。窗口模式约束字幕位置，全屏时允许应用用户设置的 100% 以上位置。

## 验证

- 本次洁净源码 Release Publish 的 Windows 编译零警告、零错误。嵌入 Web 构建仍有既有 chunk 大小和 Browserslist 数据提示。
- 停止测试前，隔离验证覆盖服务端部署、停止、重启、修改共享目录和账号保护；真实鼠标验证了按住拖动与松开停止，真实服务生成的雪碧图及时间提示持续显示超过 11 秒。Linux 服务命令包编译和 Windows 停止事件专项检查通过。
- 用户随后要求停止测试。自动隐藏计时的最后一处修正、字幕实际画面、最终包的 15／20 秒启动冒烟和安装升级未复核；此前合并版的冒烟结果不代表本次构建通过。
- 已有 GitHub 自动检查中，Windows 构建因缺少 pnpm 失败，播放器检查脚本有既有断言不一致；一次 Windows 服务端目录任务的权限撤销场景等待超时，相关任务代码与此前通过的提交相同，原因未确认且未重跑。
- 历史 UI、ZIP 解压、共享核心及其他播放器专项证据对应此前构建，不能替代本次范围的复核。

## 已知问题与待验范围

- 因版本号仍是 0.9.0，更新检查不会提示同版本替换。已安装旧 0.9.0 时需先正常卸载旧版本，再安装此构建。
- 自动隐藏最后一处修正和字幕真实显示尚未实机复核。截图中的另一端口进程已退出，其来源无法确认；正在运行的旧服务须停止后由新版重新启动，才使用新版停止机制。
- Windows 服务端目录任务的权限撤销检查有一次超时，尚不能判断是执行环境延迟还是产品问题。
- 交互式安装升级、剩余桌面拖放和文件夹批传组合、跨屏 DPI、触控、Typora 实际窗口、中文输入法组字、真实 Tailnet 入网与跨设备局域网留待人工体验。
- 关闭系统透明效果的本轮复拍未完成。高对比度为静态检查，PDF 压力复验暂停。Windows Actions 的 pnpm 环境和旧传输探针断言仍待修复。
