# Animated status icons

Animated icons by [Lordicon.com](https://lordicon.com/). The About → Credits and licenses page links this attribution. Free System Outline assets used by official builds:

- [11 Link](https://lordicon.com/icons/system/outline/11-link), `in-reveal`
- [37 Check](https://lordicon.com/icons/system/outline/37-check), `in-reveal`
- [400 Bookmark](https://lordicon.com/icons/system/outline/400-bookmark), `in-reveal`

See [Lordicon licenses](https://lordicon.com/licenses) and [attribution](https://lordicon.com/docs/license/attribution). Official Lottie exports are injected from a private, licensed asset bundle during packaging; standalone source JSON is not redistributed in this repository. A public clone builds with local static vector fallbacks. Runtime playback uses `com.airbnb.android:lottie-compose:6.7.1` ([Apache-2.0](https://github.com/airbnb/lottie-android/blob/v6.7.1/LICENSE)).

`FilewayStatusAnimation` plays an event once, respects lifecycle and system animation settings, and leaves a readable static terminal state. Historical completed tasks do not trigger completion celebrations. Package receipts record licensed asset inputs independently of the clean Git code tree.

## 1.1 navigation and interaction icons

The official free System Outline catalog identified each icon below as `premium: false`. Original Lottie geometry and marker ranges are retained; the shared renderer plays the hover marker once per interaction, and uses a visible resting frame. Assets are packaged through the same private export receipt as the existing icons. Public builds retain Material Symbols fallbacks.
