# 栖卷 Windows 0.8.62

0.8.62 收口密码输入框：把 `FwPasswordBoxStyle` 设为 PasswordBox 的隐式样式，修改密码、用户管理等所有密码字段统一为圆角输入框外观；同时修正修改密码弹窗的字段宽度与对齐。

## 本版完成

- `Styles/Design.xaml` 新增 PasswordBox 隐式样式（基于 `FwPasswordBoxStyle`：10px 圆角、1px 描边、36px 最小高度、内边距 12,7），不再依赖各调用点手动套样式。
- 修改密码弹窗：三个 PasswordBox 去掉固定 `Width=320`，改为随弹窗内容横向拉伸，标题、说明、字段左边缘对齐；不再出现 320 宽字段在宽弹窗中居中导致的错位。
- 修改密码弹窗不再在代码里查找资源字典；隐式样式对所有 PasswordBox 生效，避免资源键查找失败时退回原生外观（0.8.62b 的 `FindResource` 编译错误已由该方案替代）。
- 存储设置弹窗：内容滚动区最大高度 400→480，并在打开时聚焦“关闭”按钮，与 0.8.61 的设置类弹窗初始焦点规则一致（当前测试服务器的该菜单入口禁用，未重新截图）。
