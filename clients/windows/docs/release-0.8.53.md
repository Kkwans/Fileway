# 栖卷 Windows 0.8.53

0.8.53 给文件任务与操作记录列表补上列头，让右侧时间列与任务列有明确的扫描基准；空状态时列头自动隐藏。

## 本版完成

- 文件任务列表新增列头：左侧“任务”与任务名称同基线，右侧“创建时间”与行内时间同列；操作记录页切换为“操作 / 时间”。
- 列头使用 12px 次级文字，不引入新卡片或分隔线；列表为空时隐藏列头，避免空状态上方出现无内容表头。
- 任务行与操作记录行继续沿用 0.8.52 的左侧图标、中间主信息、右侧时间布局。
- 设计契约补充：文本列表列头不得使用独立容器，列头文字与首列内容基线一致。
