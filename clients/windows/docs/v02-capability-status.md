# 0.2 浏览与文件管理交付清单

0.2 的范围来自既有产品路线；收藏和标签不是追加需求。0.2.x 是增量包，发包不代表关闭 0.2。
本表跟随实现更新；“已实现”与“已通过真实原生验收”分开记录。完整 0.1—1.0 路线见
[产品路线](product-roadmap.md)。

| 原定 0.2 项目 | 实现状态 | 验收与剩余工作 |
| --- | --- | --- |
| 连接档案、保持登录、恢复、注销/遗忘 | 已实现，0.2.0 | SQLite/DPAPI 专项与原生旅程已有记录；最终候选跨端门槛保留 |
| 列表、网格、详情与缩略图 | 已实现，0.2.0/0.2.2 | 0.2.2 有原生截图/录屏；浏览器代表性切片仍待用户验收 |
| 紧凑密度、图标尺寸、类型筛选 | 0.2.3 代码与构建已完成，原生待验收 | 五种真实布局；紧凑网格/Windows 图标独立四档；当前目录七类筛选，不冒充服务端搜索 |
| 路径导航与排序持久化 | 部分实现 | 返回/上级已有；0.2.3 布局/图标尺寸/筛选/排序按账号目录保存；直接路径定位、列宽持久化仍欠缺 |
| 服务端当前目录/递归搜索 | 未实现 | 当前名称过滤只覆盖已加载目录，不能冒充服务端搜索 |
| 收藏及收藏分组 | 0.2.3 代码与构建已完成，纠正版原生待验收 | 侧栏直接展示收藏/可折叠分组，一击打开；独立管理与资源快捷操作。旧“只有管理入口”的界面已被拒绝，不作为验收证据 |
| 标签及关联资源 | 0.2.3 代码与构建已完成，纠正版原生待验收 | 侧栏显示真实色点/名称/关联数，一击查看关联资源；保留独立管理、绑定解绑和明确错误 |

| 主动 MD5/SHA1/SHA256 文件校验 | 未实现 | 使用既有 checksum API；耗时操作可取消、离开 UI 线程 |
| 新建文件/目录 | 目录服务已实现；界面及新建文件未实现 | 需完整原生操作与冲突结果 |
| 重命名与批量预览 | 单项重命名服务已实现；界面与批量未实现 | 保留 opaque 路径、目标冲突和逐项预览 |
| 复制/移动 | 未实现 | 现有 Windows Files 服务仅有 mkdir/rename/trash；需接服务端任务 |
| 回收删除/恢复基本旅程 | 回收删除服务已实现；界面和恢复未实现 | 明确 trash，恢复冲突和部分结果可解释 |
| 服务端任务与操作结果 | 部分结果模型已实现；任务服务/界面未实现 | 取消请求不等于取消完成，未知写入不重发；持久核实仍待完善 |
| 通用键鼠/右键/快捷键 | 部分实现 | 多选、Enter、返回/上级已有；写操作与剪贴板关联快捷键待接入 |
| 浏览器 A 方向明暗/原生切片 | 基础已实现；未完成验收 | 收藏/标签及冲突/任务等状态完整后提交代表性切片，不默认为用户已批准 |

## 当前交付批次

0.2.3 接通已经欠缺的收藏/分组、标签并按 Web 的侧栏快跳与五种视图纠正交互；将本地外挂字幕上限提高到
500 MB（500,000,000 bytes）。服务/数据专项已通过，纠正版原生验收尚未完成。随后继续本表的服务端搜索与文件操作、回收/任务、
浏览偏好/最近访问/校验等剩余事项。既有 0.2 范围不因增量包或优先顺序改变而删除。

每批统一执行相关构建、专项和真实原生旅程，先收集问题再集中修复复测；不重复回归无关模块。
只有本表必需项目都有实现/验证归属、原生切片用户验收及完整旅程通过，才关闭 0.2 里程碑。
