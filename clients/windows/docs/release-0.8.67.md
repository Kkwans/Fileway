# 栖卷 Windows 0.8.67

0.8.67 做了一轮最小窗口（1200×900）排版复核，并修正主浏览页顶部工具栏的尺寸不一致：返回/上级/刷新原先 32px，与 40px 的路径栏、搜索框上下错位。

## 本版完成

- 新增 `BrowserToolbarButtonStyle`（40×40、10px 圆角），只用于返回/上级/刷新；路径栏内的编辑按钮仍保持 32px 内嵌尺寸。
- 顶部工具行现在三个导航按钮、路径栏、搜索框同为 40px 高，1440 与 1200 宽度下上下边缘对齐；焦点环、禁用态与点击区域随按钮放大。
- 最小窗口复核：最近访问、传输中心、文件任务、回收站、存储工具、主浏览页均无溢出/错位；文件任务筛选栏的 380/140 固定列宽为既有设计，未改动。
- 截图保留在 `screens/min1200/`（各页面）与 `screens/browser/`（1440/1200 主浏览页）。
