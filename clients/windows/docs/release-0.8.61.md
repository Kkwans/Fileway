# 栖卷 Windows 0.8.61

0.8.61 继续收敛设置类弹窗：为「交互与外观」增加分组标题和自动保存说明，并让设置对话框初始聚焦“完成/取消”，避免首屏第一个滑块/下拉框带出系统焦点框和悬浮数值。

## 本版完成

- 「交互与外观」拆为“提示与播放 / 界面背景”两组，宽度调整为 320，补“修改会立即保存”说明。
- `DialogOrdering` 新增设置类对话框的初始焦点：打开「交互与外观」「打开方式」时聚焦关闭按钮（完成/取消），不再默认聚焦第一个控件。
- 修复首屏第一个 Slider 的系统焦点框和数值悬浮提示遮住标题的问题；取消按钮使用自研双色圆角焦点环。
- 打开方式双栏布局与保存/取消顺序保持不变。
