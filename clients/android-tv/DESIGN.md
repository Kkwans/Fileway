# 栖卷 TV：内容与遥控设计

本规范取代旧版 TV 视觉基线，适用于影视首页、详情、季集、片源、文件、设置、播放器及手机遥控的对应表达。共享字体、图标、颜色、状态、动效遵循 [原生设计系统](../../docs/design-system.md)。目标是 Android TV 1.0；本文件不是原生实现、用户视觉认可或投影验收凭据。

播放器采用已认可方向的暖色影片背景与克制中性深色表面关系，继续细化同一语言。柔和表面由静态遮罩与色层实现，不采样/模糊视频；生成图中的图标必须换成许可明确的共享矢量。方向认可不等于实现、80寸投影或最终视觉验收。

## 布局立场：先把内部设计做对

底部大面板是有效的TV交互形态，大小本身不是缺陷根因。同一窗口/字号下各播放器Tab共享等高外框、Tab栏位置/高度和内边距，切Tab不移动顶线/底线或改变整体尺寸。设计首先修复内部网格、信息关联、视觉层级、字体与图标光学对齐、密度、材质和状态，不以换成小弹层回避。合理留白承载秩序，不以假信息填满；目标是有质感、精致、现代的媒体界面，不是旧控件换色或机械灰色选项墙。

绿联官方 [TV音频操作说明](https://support.ugnas.com/detail/article/zh-CN/880) 的 [播放器图片](https://file-ap.ugreennas.com/admin/article/2026-10-20/0bdb8557f78747f794291930959211f8.webp) 仅证明宽底部容器这种结构存在。用户明确认为该音频Tab是绿联TV最不满意的设计，故它不是审美标杆、认可证据或值列/焦点风格模板。该文同时谈Apple TV和Android TV，未标明图的具体平台/客户端版本；其他TV设置/字幕/倍速/列表的逐图对照仍待获得可靠画面。以下内部网格来自栖卷任务、已认可整体原型与统一设计语言，不从这张音频图推导质量结论；PC/Web/手机画面不能替代TV证据。

## 空间与网格

基准960×540dp，按实际窗口dp布局，不能按1080p/4K物理像素指定字号。背景图和视频出血全屏，重要文字/操作默认左右48dp、上下28dp安全区；已有校准在根层统一应用，不逐层再加5%。HUD顶信息同样进安全区。

| 角色 | 基准数值 | 自适应规则 |
| --- | --- | --- |
| 页面内容区 | 864dp宽；左轴48，右轴912 | 窗口扣安全区，紧凑视口先减列 |
| 概念栅格 | 12列，列宽(W−11×16)/12，列间16 | 约束主要对齐线，不强制所有控件拉满 |
| 全局导航 | 高48、顶28、栏目间16、图标槽48 | 长标签可滚动，不挤压字号 |
| 区块 | 区块间32，标题到内容12 | 同组卡片间16，内部8/12 |
| 影视海报 | 默认6列，宽130.67，图片2:3 | 最小128dp；字号增大减少列数 |
| 续播/集卡 | 16:9，宽272dp，三列 | 独立于海报与文件列数设置 |
| 文件网格 | 保留用户2–6列/列表，默认4列 | 不把文件缩略图强制裁成影视海报 |
| 卡片文字 | 标题顶间8，两行20/28sp，元数据16/24sp | 同组固定标题槽，完整标题从详情读取 |

焦点溢出保留8dp；首尾卡片完整轮廓保持可见。Lazy列表按完整目标入视口滚动，每行记忆稳定身份，上下尽量保持列位置，数据补入不跳首项。标题与文字按基线，图标与单行文字按光学中心对齐，不靠手动空格/固定空白占位对齐。

## 导航与首页

顶部主导航：栖卷品牌、影视、文件、音乐、图片、收藏；右侧搜索和设置。影视是真实媒体目的地，不能把旧视频文件筛选页改名当影视库。二级详情收起全局导航，保留返回/来源页名和必要动作。服务切换在设置内，不在普通内容卡重复账号。

首页是垂直连续内容流：新入库、独立继续观看、分类海报。导航后16dp进入hero；hero正文最大480dp宽，内容高约220–260dp，后续自然出屏。不为三组同屏把字体降到12sp或把2:3图改方图。

- 新入库最多5个有权且匹配的作品；标题36/44两行、元信息18/28、简介两行。主动作“查看影片”，播放次要；详情中播放为主。8秒轮播，焦点进入、触摸/鼠标操作或弹层暂停，不能切走准备确认的作品；单项不伪造分页。
- 继续观看横图+作品/集名+真实进度与剩余时长。未知时长不画比例。确认续播，可见更多提供详情、从头播放、移出续播，后者不删历史。
- 分类：全部/电影/剧集/综艺/动漫/纪录片。确认切换，当前行加载不清空整页。空行隐藏；首次空库提供建库或有权管理途径及文件入口。
- 海报评分标来源、时长/收录集数取真实数据。“12/24集”仅在总数可信时使用。人物、合集、筛选结果复用同一卡片体系。

## 详情、季集与片源

详情背景全屏，左信息区maxWidth520dp，返回行48dp；标题、元信息、评分、简介、操作共享左轴。主播放、片源、收藏、已看同组；空间不足次动作换行不缩字。评分先显示最多3组并可展开；缺值不补0。片源摘要只含有权看到的剪辑/质量/库名。

简介展开可完整读；演职员区分导演/编剧/演员并可反查作品。无背景回纯canvas+真实海报，不使用上一作品图片。标题图仅用获准媒体logo；缺失用UI标题，不模拟生成图的书法字体。

剧集有季选择和序号/卡片模式两个控件。观看状态决定初始季，否则首个有内容季，特别篇独立。16:9集卡含序号/标题/时长/观看状态；序号项至少56×48dp。各季保留滚动锚点；未收录、离线、失权不是同一状态。

片源从右出现，基准456dp宽，复杂内容可至520dp，上下28、右48、内部24；最大高484dp，正文滚动。标题、作品名、剪辑Tab、来源列表、确认动作形成稳定层级；一项时按内容收敛。来源行最小104dp，图标32、间距16、末端状态24，长文件名换行或展开。

剪辑是一级分组，编码副本为同组来源。当前播放、待选择、焦点独立；焦点移动不选源，确认选中，底部“使用所选片源”才提交。详情内选源只修改待播放来源，是否播放由入口动作明确表达。离线/授权过期/需重定位/失权显示真实原因，仅有权恢复动作可激活。播放权限不扩展成原目录浏览权限。不同剪辑断点独立；同剪辑编码副本仅在时间轴可靠等价时复用断点，没有证明不套旧时间。

## 文件与设置

文件页与影视共用标题、工具栏、焦点语言，但保持文件真实比例/名称/路径和列数设置。未经识别文件不假造元数据。详情、打开与其他动作从可见更多可达，长按只是快捷。

设置整页可用168dp类别区+24dp间距+有界内容区；不足时类别列表→内容单页。行内名称、说明、当前值保持明确关联，值不甩到整个屏幕另一端。字号/安全区调整同页有实际预览、恢复默认可达。只读技术信息不创建假操作焦点。

## 播放器 HUD

稳定SurfaceView保持全屏，HUD/暂停按钮/菜单不改变Surface布局或重建播放器；保留原始源时间轴、ASS字体及PGS身份。无视频帧复制/实时模糊。

顶行x48/y28：北京时间20/28sp固定槽、间距16、片名20/28sp弹性槽、间距16、速度18/24sp固定槽。长文件名一行截断、信息页完整可读，不挤出安全区。时钟与速度独立可设常驻/随HUD，使用共同薄顶部遮罩，不加单独盒子。

底部距安全边28，操作行48dp，上方8dp间隔与48dp时间轴交互区。可见线4dp、thumb10dp；当前/总时长固定数字槽。左组队列/设置，中央上一项/播放暂停/下一项，右组倍速/字幕/音轨；组内8、组间至少24。主传输几何中心不随左右标签宽度漂移。

时间轴只画有可靠时间映射的区间。连续引擎缓冲与磁盘缓存分开；VBR字节比例不能画成时间覆盖。信息区分别标“连续缓冲至”“磁盘缓存/上限”“传输速度”；未知映射显示“暂无时间范围”，容量满不等于全片可连续播放。手机远控字段语义相同，seek后缓存实际保留/失效须有运行证据，不能只改数字。

## 宽底部面板的内部设计

首个设计比较基准固定同一外壳：x48，width864dp，底距28dp；基准height272dp（包含48dp任务Tab、8dp间隔与216dp内容区）。背景统一中性深色，静态遮罩与内容分层；Tab和正文共用x72起点。选中Tab2dp短线、焦点2dp轮廓互不替代，无忽然变化的粗胶囊。标题/Tab本身能说明任务时不重复再加一行同名大标题。

内容区内左右24dp、上下16dp，得到816dp工作宽。横向可分成396 + 24 + 396；两侧内部都按“24图标 + 12间距 + 名称/值组 + 24末端槽”对齐。组之间留白、组内关系紧凑，不把每行label固定在左端、value固定到864dp另一边。对称取决于相同任务权重，非强制两栏等高。

| 面板 | 内部构图与实际关系 | 焦点/选中与少量数据 |
| --- | --- | --- |
| 设置 | 两列各3行，行高最小56、行间8；左列播放速度/画面比例/播放信息，右列音量/动态范围/退出。每个396dp槽内标签和值相邻、末端24箭头统一 | 一行一个动作；成对列的文字首基线一致，长值转第二行并让同排共同增高；可用高度不足正文滚动 |
| 倍速 | 左区“播放速度”与确认值、当前状态说明，右区预设/精调；或全宽同任务的预设行+slider，二者必须同一水平起止轴 | 预设选中保留勾选，slider焦点轮廓独立；当前值贴标题/slider不孤悬正中。范围来自实际引擎，非设计扩权 |
| 字幕 | 左168dp任务选择，间距24，右624dp轨道/添加/调整；左右首行同高同基线，右区内部label/value有界 | 只两项时两行在顶部稳定排列，下面留白为同一表面，不用假选项填满；左选中与右焦点均可辨认 |
| 音轨 | 轨道行最小56dp，间隔8dp，18/28sp名称与16/24sp格式优先同基线。1–3项使用有界单列；4项起在两列各有360dp及24dp列距时按行排列。字幕右侧工作区宽度不足两列时使用同一单列 | 选中底与勾选独立于2dp焦点环。长名称和格式可换行，同排按最高项增高，末项完整入视。两列上下保持列号，缺右项时落到左项 |
| 信息 | 2列主题分组，每组396dp，标签与值在同列连续；“片源/播放路径”与“解码输出/缓存”并列，展开技术详情可纵滚 | 只给展开/复制等动作焦点，整信息区没有巨框。unknown→未识别，missing→暂无信息，unsupported→不支持 |
| 队列 | 横图16:9与两行标题/集名/当前播放标记紧密组成一张内容项；多项横排。单项可用128×72图+邻近文本的完整媒体行，仍留在相同宽面板 | 当前项标记不等于焦点；1/2/多项均有正确基线和标题槽，余白不靠伸长缩略图填充 |

同组Tab外框始终等高，不能按每个Tab条目数自动缩高。窗口或字号变化时整组用同一规则适配高度，最大不超过安全区；长内容只在正文滚动，Tab/返回可达。少项通过成组信息与有意留白形成视觉平衡，不用固定灰底行填墙。HUD触发的独立快捷选择层可320–440dp宽并按内容测量，但它不是完整Tab组的一种自动缩小状态。两种组件共享字体/圆角/焦点，层级和返回明确。

连续调节即时生效，沿用既有范围/步长；左右精调只在slider焦点，长按合并最新请求并最终提交末值，失败回退已确认值。普通字幕字号/位置不覆盖ASS源样式；不适用控件解释原因。字幕添加支持当前服务器/本地真实来源，关闭子页回到添加入口。

## 暂停、返回与退出状态机

hudVisible、activePanel、playbackState、exitPromptDeadline分别建模。暂停中心按钮是状态的可激活反馈，不等于底部HUD可见，也不是必须先关的modal。

| 当前状态 | 画面/确认 | Back |
| --- | --- | --- |
| 子页/选择层 | 仅最上层活动 | 退一层并恢复触发项，不产生退出提醒 |
| 完整面板 | 面板拥有焦点，背景HUD/中心按钮不可操作 | 关面板回触发控件，不穿透退出 |
| HUD可见、无面板 | 确认执行具体控件 | 仅隐藏HUD并清除旧退出提醒，不提示二次返回 |
| 正在播放、HUD隐藏 | 无中心播放按钮；确认暂停，左右seek，上呼HUD、下菜单 | 第一次显示2秒退出提示，第二次独立Back退出 |
| 已暂停、HUD隐藏 | 中心72dp按钮持续可见，32dp播放图标，名称“继续播放”；方向键可进HUD | 按HUD隐藏流程退出，不能因为中心按钮存在永远无法退出 |
| 已暂停、HUD可见 | 中心按钮表达暂停；底部焦点不被它抢走 | 隐藏底部HUD，中心按钮保留；下一次Back才开始退出提醒 |
| 恢复请求中 | 保持暂停/处理中反馈，禁重复提交；真实成功后才变播放状态 | 按HUD/面板实际层级，可退出，不被busy锁住 |
| 准备/缓冲且播放意图为播放 | 持续400ms后“正在缓冲”，不以播放按钮冒充暂停 | 按HUD/面板层级 |
| 自然结束 | 有下一集显示10秒连播倒计时、取消/立即播放；否则重播/返回 | 先处理活动结束层，再按播放器层级；不当作暂停 |

二次退出提示与±10秒反馈使用相同中心位置、半透明材质和字阶，文案“再按一次返回退出播放”。需要第二次独立按下/抬起，长按重复不能算两次；2秒过期自动撤销，其他有效操作清除。中心暂停按钮与短反馈共用中心区，反馈临时替换可见内容，结束恢复暂停按钮，不改变实际暂停状态；不堆叠四层提示。

暂停中心按钮激活只发送一次恢复请求，不传播成视频单击切HUD。手机远控从带连接/媒体代次的实际状态显示播放/暂停，请求中保留已确认状态，真实成功后更新，不能先乐观翻转成两端矛盾。

播放中HUD默认5秒无操作隐藏，保留已有2–30秒设置；暂停可保持HUD但Back能关闭，触摸探索/拖动/面板/正在调节期间不自动隐藏。触摸单击切HUD、双击播放暂停。seek/rebuffer延迟反馈和旧定时器取消遵循共享规范，禁止每次seek闪0%。

## 遥控、异步与可访问性

D-pad 焦点移到播放器面板 Tab 时立即切换正文，焦点留在 Tab 栏，向下进入正文，向上回当前 Tab。鼠标和触摸点击切 Tab。设置值、轨道与其他操作由确认或点击提交。列表返回按稳定身份恢复。连续输入即时更新逻辑焦点，动画不排队。只保留一个活动域；面板后台不可点击/获焦/读屏。

返回保存originFocusKey、scrollAnchor、sessionGeneration；旧异步结果不抢焦点。失权/删除回到相邻有效项或标题；账号切换清私有图像和旧锚点。所有动作同时支持遥控、触摸与鼠标，不把长按当唯一入口。TalkBack读角色/当前值/已选/禁用原因，不每秒播报进度。

手机遥控保持设备/连接状态、遥控/文件/播放/设置Tab，授权只在实际需要时出现；一次控制一台TV，发现不等于信任，TV独立会话不随手机静默切换。连接/媒体代次变化取消拖动和旧请求；接力包含设备选择、显式授权、真实阶段与恢复，成功事件仅消费一次。

## 验收边界

组件先覆盖静态状态和真实行为，再集中验收完整导航→详情/季集→选源→播放→返回旅程。包含相同宽底面板下1/2/多项、长中英文字、亮/暗影片、浅/深主题、快速遥控、失权/恢复。不能通过缩小范围回避内部设计。

记录具体候选、80寸投影实际阅读距离、显示缩放/密度及用户视觉反馈。设计板、源码、编译、模拟器、物理音画、用户认可各是不同证据。既有返回焦点与兼容seek故障需复现和根因闭环，新视觉不掩盖行为失败。
