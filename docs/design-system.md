# 栖卷原生设计系统

本规范定义 Android 手机 2.0 与 TV 1.0 的共同视觉语言和组件契约。它替换旧文档中粉色强调、不同圆角、整屏灰色选项墙等历史方向；描述目标而非实现或验收完成。端侧布局分别见 [手机规范](../clients/android/docs/design-system.md) 和 [TV 规范](../clients/android-tv/DESIGN.md)。

## 设计立场

内容发现是 Experience，筛选、选源、文件与设置是 Operate。让真实封面承担色彩，文字和控件保持安静、准确。质感来自网格、字阶、留白与连续操作，不来自实时模糊、重复描边、装饰渐变和层层卡片。

TV宽底部面板本身是有效形态。播放器同组Tab在同一窗口/字号下共享稳定外框高度、Tab位置和内边距，切换不跳顶线/底线；内容溢出内部滚动，稀疏内容有意构图。先完成内部网格、信息关联、层级、光学对齐、材质与状态，不能按单个Tab内容多少缩高或以换小面板回避设计。独立片源Sheet/快捷选择层可另按内容测量，不属于这一等高Tab组。

所有页面遵守三条对齐轴：页面内容起点、组件内容起点、末端动作槽。标题与文字按基线对齐，图标按视觉中心对齐；不能用空格拼表格。视觉平衡不等于所有列等宽或把少量内容拉满。同组卡片稳定高度；播放器Tab组共享外框高度以保持切换连续性，内部内容按各自任务组织。

已认可的首页、详情、片源、手机详情概念图决定内容关系和沉浸方向；原型中的花体片名、封面、评分和片源参数不是生产资产。用户投影实拍是缺陷证据，旧实现不是新的视觉权威。

## Token 分层与实现归属

1. `clients/shared/android/design-foundation` 保留共享颜色角色、形状、间距、文字基础与已授权矢量，不引入 phone Material3 或 TV Material 控件依赖。
2. 手机 `ui/designsystem` 与 TV 组件各自适配尺寸、输入与 Material 语义。共享语义不意味着手机控件等比放大。
3. 页面只组合角色与组件，不局部重写另一套焦点、loading、字号和圆角。一次性详情构图留在页面，不抽象成万能面板。

当前事实：两端 Compose BOM 固定 `2026.09.00`；手机 Material3 使用该 BOM、最低 API 29；TV `androidx.tv:tv-material:1.1.0`、最低 API 28；现有 Lottie Compose `6.7.1` 仅手机可选授权图标使用。本规范不要求升级这些依赖。现有 `FilewayPalette` 的深蓝灰值及端侧组件仍需后续逐片迁移，不能从文档推断已生效。

## 字体与文字度量

| 对象 | 字体与来源 | 字重与回退 |
| --- | --- | --- |
| TV 中/英/数字 UI | 已随包 Noto Sans SC 2.004 静态 Regular/Medium；复用 `fileway_ui_regular.otf`、`fileway_ui_medium.otf` | 400 正文、500 标题/操作；不合成 600/700，不用字体缩放模拟粗体。缺字交 Android 系统 fallback，罕见姓名、扩展汉字和其他语系需真机确认 |
| 手机中/英/数字 UI | 既有 `FontFamily.SansSerif`，遵守用户系统字体；AOSP Latin 常见 Roboto，CJK 由平台 fallback 决定 | 400 正文、500 操作与区块、600 页面/作品标题；OEM 实际字形不能宣称固定 Noto。字体不可用时交系统回退，不联网下载字体阻塞首屏 |
| 时间/大小/速度/集数 | 使用各端相同 UI 字体，数字角色启用 `tnum`，固定值槽按当前字体测量 | 400/500；若设备字体不支持等宽数字，槽宽按该格式最大度量固定，不把整行换为代码字体 |
| 片名图、字幕、文档 | 片名仅使用来源获准的 logo 图；缺失用作品标题角色。ASS/外挂字体、PGS 是独立媒体资源 | UI 字体不能覆盖 ASS 样式/字体，也不能用 UI 模糊或蒙版替代原生字幕 |

Noto 字体两文件合计 16,676,772 字节，已在 TV 包中；本轮不复制到手机、不扩大包体。TV 原始校验与来源保留于 [README](../clients/android-tv/README.md)，随包 `noto-sans-sc-OFL.txt` 包含 Adobe 版权与 SIL OFL 1.1。OFL 允许随软件分发但须保留许可与版权，修改字库须处理保留名称，不能默认把子集当原文件。官方许可见 [Noto Sans license](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)。

| workTitle 作品标题 | 28/36，600 | 36/44，500 |
| pageTitle 页面标题 | 24/32，600 | 28/36，500 |
| sectionTitle / panelTitle | 20/28，500 | 24/32，500 |
| itemTitle / emphasis | 16/24，500 | 20/28，500 |
| body / value | 16/24，400 | 18/28，400 |
| action / navigation | 14/20，500；主播放16/24 | 18/24，500 |

沿用 `includeFontPadding=false`、行高居中、`Trim.None`；多行标题按实际 lineHeight 预留，不以固定 px 裁字。CJK 不加字距；Latin 正文不全大写或拉宽，电影原始标题保持原文。中英数字混排以同一文字 run 为优先，避免每字段单独垂直居中导致基线错位。

作品标题最多两行；极长标题通过详情正文/展开完整可读。海报标题稳定两行，元数据一行；文件名规则由文件模式决定，不能把影视标题截断规则套到无界文件瀑布流。正文每段手机约 18–26 个汉字、TV 约 24–32 个汉字宽；不靠缩字号塞内容。界面字号响应系统和已有应用字号设置，不新增硬性倍率上限。字号变大时减少列数、让按钮换行、把双列改单列、正文滚动，保留完整操作。

## 图标

普通操作、播放器、设置与新影视导航统一 Material Symbols Rounded：`wght=400 / GRAD=0 / opsz=24 / FILL=0`，选中导航可用同符号 FILL=1。复用共享 `fileway_ic_*` 资源；官方路径固定 commit `49d4db35df873165d6bd6ba09b063c7dafbac2f4`，保留 960 viewport、几何和 Apache-2.0 声明。见 [本地来源表](../clients/android/licenses/material-symbols.md) 与 [官方指南](https://developers.google.com/fonts/docs/material_symbols)。

| 用途 | 可见图标 | 命中区 / 留白 |
| --- | --- | --- |
| 手机普通操作、底部导航 | 24dp；次要行尾20dp | 至少48×48dp；文字间8dp |
| TV 普通操作、行首/行尾 | 24dp；主传输28dp | 至少48×48dp，主播放56×56dp |
| TV 暂停中心播放 | 32dp | 72×72dp圆形/圆角容器；不改变视频Surface |
| 信息/状态图标 | 手机20dp、TV24dp | 不可操作图标不创建假触区/遥控焦点 |

视觉光学修正最多 ±1dp，由图标组件统一声明，不逐页面手调；保持原始纵横比，不加描边改造现成矢量。播放等方向性内容不随 RTL 翻转，导航返回等使用已声明 auto-mirror。图标按钮必须有动作名称；相邻可见标签已说明时图标不重复读屏。

已有手机 Lordicon 免费授权导航组允许保留一次动效和静态终帧，但完整五项必须同家族同节奏。新增影视图标若没有同组已核验免费导出，整组使用 Material 静态版，不能四个 Lordicon 加一个风格不同的图标。以 [许可清单](../clients/android/licenses/lordicon.md) 与实际打包收据为准，不把“网页可看”视为获准再分发，不新增 PRO 依赖。TV 全部静态，不加载 Lottie。概念图图标、emoji 和任意绘制轮廓不作为生产图标。

以下为目标角色；不启用壁纸动态取色。图片可以有丰富色彩，UI 的蓝只表达动作、进度和有限状态。播放器在浅色应用主题下仍保持同一中性深色材质。

主播放：手机 accent/onAccent；TV `#F1EEE7` / `#17191D`，不把所有按钮变成白底。其他 TV 动作 surfaceRaised/textPrimary。评分不创建新的品牌色：标签用 textSecondary，数值可用 warning；来源名称始终可见，缺评分省略，不能补0分。

文本对比目标 ≥4.5:1；焦点/可操作边界与相邻表面 ≥3:1。dividerDecoration 只是分组，不承担唯一交互边界。状态还须有文字、勾选或形状，不仅靠颜色。禁用文本不降低到看不清的透明度；使用 textMuted 与明确禁用语义，原因在同组说明。

媒体遮罩独立于页面主题：

- 背景图铺满，文字区覆盖稳定深色/浅色渐隐，不以逐帧采样颜色改变文字。亮色手机详情在正文接缝处达到不透明 canvas；暗色详情同理。
- TV HUD顶部从黑色80%渐隐到0；底部操作文字所在区域至少黑色80%，向画面主体渐隐。时钟/速率没有单独盒子，但有共同顶遮罩；常驻时保留薄遮罩保护文字。
- 播放任务面板 `#17191D` 92% alpha，反馈同色84% alpha、textPrimary。边缘可用1dp白色12%装饰边，不使用实时模糊。最大亮度/最暗画面均需检查合成后对比，透明度不是无条件保证。
- 浅色页 modal scrim 黑色32%，深色48%；遮罩代表后台不可操作，不能只视觉变暗却让焦点穿透。
- 减少透明效果/目标设备对比不足时，改不透明 surface，不改字体颜色去追视频。

## 间距、形状与对齐

间距刻度 `4 / 8 / 12 / 16 / 24 / 32 / 48dp`：图标文字8、同组12或16、不同任务24或32；页面大结构48。普通控件、卡片、菜单、面板12dp圆角；图片角、焦点环和剪裁同形。语义圆形播放按钮与头像为例外，底部附着面板只有可见上角圆角。

组件必须先分配末端值/动作槽，再分配名称可用宽。单行设置：leading icon24 + gap12 + label.weight(1) + gap16 + measuredValue + gap8 + trailing24；仅在受约束的内部列宽使用weight。TV宽864dp底面板先扣左右24dp，再划为396 + 24 + 396dp两列；每行只占所属396dp，值不甩到整块面板另一端。纯动作行如“退出播放”没有重复“退出”值，不为填列造文案，末端动作槽仍对齐。长值转第二行，label/value顶部基线对齐。端侧定义的56/64dp为最小高度而非硬裁切，字号增大自然增高。

## 独立状态矩阵

`selected` 是持久选择；`focused` 是下一次遥控/键盘确认的目标；`hovered` 是鼠标位置；`pressed` 是按下尚未完成；`busy` 是真实请求。它们可以组合，不能相互替代。

| 状态 | 视觉 | 输入和语义 |
| --- | --- | --- |
| rest | 基础表面，无外框 | 可激活对象才可获焦 |
| selected | 同组 tonal 底 + 独立勾选/状态文字；Tab用2dp短线 | `selected=true`；移动焦点不修改选择 |
| focused | TV 2dp focusRing、与内容间2dp保留；手机键盘同角色 | 一个活动焦点；新输入立即迁移焦点，动画可追随但不延迟输入 |
| selected + focused | 保留勾选/短线，另加相同焦点环 | 同时读出已选和动作，不用焦点框表示已选 |
| hovered | 同色 surfaceRaised 轻微提升，无TV焦点环 | 不自动抢遥控焦点；移动鼠标不切Tab/片源 |
| pressed | 轻微明度变化；内容卡可从1.025回到1.0 | 不反复发请求；释放/取消恢复准确状态 |
| disabled | textMuted，去hover/pressed反馈，原因可读 | 原因/恢复入口可达，禁用动作不响应确认 |
| busy | 原位状态文字/延迟小环，保持按钮尺寸 | mutation 禁重复提交；可取消操作保留取消；不锁住整页 |
| unavailable / denied | 明确原因 + 有权限执行的恢复动作 | 不泄露他人库名/路径；不能假装禁用播放可重试恢复权限 |

焦点卡最多1.025倍，仅渲染层缩放；网格预留8dp视觉溢出。面板行、Tab、设置不缩放。焦点环画在不会被裁切的保留区；不可操作的信息整区没有巨大轮廓。手机底部导航延续已确认的无灰色ripple/按压底要求，保留语义焦点和一次图标反馈；其他触摸控件复用原生 indication。

## 组件目录与组合规则

| 组件 | 必备输入/状态 | 组合约束 |
| --- | --- | --- |
| Navigation / Tabs | destinationId、selected、focus、可读标签 | 同组固定几何，切换不改变文字权重宽度；主导航点击/确认切换 |
| PosterCard | 稳定workId、artRef、标题、真实评分来源、访问状态 | 2:3；图与两行标题/元数据分区；不嵌小按钮抢TV焦点 |
| ResumeCard / EpisodeCard | work/episodeId、16:9图、真实进度、源/剪辑信息 | 未知时长无假进度；当前播放与焦点各自显示；续播动作与详情动作可达 |
| Action / IconAction | label、icon、enabled、busy、kind | 一个任务一个主动作；操作图标无长按唯一入口 |
| SettingRow / ChoiceRow | label、value、selected、reason、onActivate | 值槽对齐；完整行是一个动作；信息文本不拆多个假焦点 |
| ValueSlider | min/max/step、requested/confirmed value、error | 实时反馈，异步请求顺序受控；失败回到已确认值并说明 |
| TaskPanel / PlayerTabbedPanel | title、content、actions、originFocusKey、groupViewport | 一个标题/关闭层级；独立Sheet按内容测量，播放器同组Tab外框等高稳定，正文独立滚动 |
| SourceRow | clipId、sourceId、已验证能力、选择/当前/失效 | 当前正在播放不等于待选择；不能凭文件名推断能力 |
| Status / Empty / Error | scope、message、action、requestGeneration | 不用假内容填空；范围内重试，不清空已有可用内容 |
| PlayerHUD / Feedback | 实际播放状态、输入域、原始源时间轴 | 稳定视频Surface；反馈不抢焦点/触摸/读屏朗读队列 |

每个组件至少覆盖默认、焦点、选中、选中+焦点、按下、禁用；异步组件另含加载、空、错误、恢复与失权。布局示例不能只展示成功满数据。消失条目以稳定身份回退到相邻项，不以过期数组下标恢复。

## 动效与反馈时序

| 目的 | 手机 / TV时长 | 曲线与取消 |
| --- | --- | --- |
| 按下确认 | 80 / 80ms | Linear；抬起或取消从当前值返回 |
| 焦点/hover变化 | 120 / 100ms | FastOutSlowIn `(0.4,0,0.2,1)`；新目标接管，不排队 |
| 选中标记 | 160 / 120ms | 同上；先更新语义，再播放视觉 |
| 面板进入/退出 | 220/160 / 180/120ms | 进入 LinearOutSlowIn `(0,0,0.2,1)`；退出 FastOutLinearIn `(0.4,0,1,1)` |
| 页面关系转换 | 220 / 180ms | 轻微淡入；不让视频Surface缩放或重新挂载 |
| 封面加载完成 | 160 / 120ms | 同一个资源身份下淡入，不从上一账号图片交叉淡出 |
| 轮播 | 300ms，驻留8秒 | 用户进入/操作/弹层暂停；回到空闲重新计时；关闭自动轮播立即生效 |

不弹跳，不滚动出现动画，不为每张卡片加延迟，不循环呼吸阴影。系统移除动画时缩放/位移关闭、视觉直接到达终态；必要加载状态改静态文字，反馈时序仍保留防闪逻辑。生命周期暂停取消动画，后台不继续消耗帧。

通用加载：请求开始先保留结构与旧的同身份内容，持续300ms才显示加载符号；播放器 seek/rebuffer 延迟400ms。完成/失败/取消、账号切换、媒体切换后旧定时器必须失效。已显示加载在真实完成时立即撤销，不为了最低显示时长继续遮挡。不到阈值的请求从不闪0%。只有存在明确分母、真实已完成量且语义正确时才显示百分比；引擎缓冲阈值不是全片下载率。

Seek 和 loading 共用中心反馈位置/材质，seek文字更新后800ms无新输入自动退场；连续输入只更新同一个实例。若400ms后仍缓冲，以“正在缓冲”替换seek文案，不能叠两层。错误改可操作恢复面板；成功不再追加多余toast。普通通知3秒、带撤销/动作5秒，并服从无障碍超时；同错误合并，可关闭。视频退出提示2秒，见TV状态机。

## 输入、异步与可访问性

- 48dp是两端触摸命中区下限，不等于所有可见图标48dp。方向键次序与可见网格一致，鼠标/触摸和遥控共享同一个动作，不建立三套业务行为。
- TV 播放器面板 Tab 随 D-pad 焦点切换正文，焦点留在栏内以便继续左右切换，上下进入/离开正文。触摸和鼠标点击切换。其他 TV 页面导航沿用各自的确认行为。选项焦点移动不提交，slider 上的左右才调整。长按与连按合并到最新意图，不排队播放10次动画或10个Toast。
- 面板打开记住 `originFocusKey + scrollAnchor + sessionGeneration`；关闭只在同身份恢复。弹层后台不可获焦、点击或读屏遍历；账号切换不能恢复旧列表锚点。
- 加载结果只回填请求所有者；用户已移动焦点后不得异步抢回首项。列表刷新保留当前位置；被删除/失权项目清除私有缩略图，恢复到相邻有效项或页标题。
- TalkBack包含角色、标题、当前值、已选/禁用原因、可用动作；进度提供有界range语义，不每秒朗读时间；错误宣布一次。无图海报提供作品名，装饰图片不重复朗读。
- 返回遵循原生系统返回；IME先关闭，子面板先返回，页面再返回。未提交表单根据真实脏状态确认，不对普通浏览弹确认。

## 证据与可实施门槛

设计板验证构图和状态表达；源码检查验证token/契约；构建验证集成；用户视觉认可与具体手机/80寸投影的真实操作分别记录。任何一种不能替代另一种。

先交付token/代表组件，随后按首页→详情/季集/片源→文件/设置→完整HUD组合推进。每个完整批次覆盖亮/暗背景、长中英标题、1/2/多条目、快速输入、返回恢复、空错失权。人工验收由用户执行的范围不擅自加设备旅程；必要原生构建与已报告故障的定点诊断由主任务安排。
