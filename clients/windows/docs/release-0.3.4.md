# 栖卷 Windows 0.3.4

本次是可靠传输里程碑的首个批量下载增量，不表示整个 0.3 范围已经完成。

- 多选普通文件后，一次预检并确认清单、总数量、总大小和实际默认保存位置。
  单次最多 100 个文件；目录明确跳过，不递归。预检失败、目标名称碰撞和未完成预检的项逐项列出。
- 只有明确确认的草稿才可提交；每个草稿最多提交一次，异常结果不自动重复提交。
  确认前的账号、会话、目录或选择变化会作废当前预览；确认后可继续浏览，队列仍绑定原账号与激活身份。
- 当前进程以 FIFO 顺序处理最多 100 个未排空任务，包含运行、排队和取消中的任务；只有一个实际下载 writer。
  上传占满共享执行预算时，仅在数据库证明没有任何执行、源或文件证据的前提下等待准入，不重放已经开始的 GET。
- 排队项可直接取消和删除，不等待前一个大文件。取消先持久化意图，在该任务的 OS 锁下，以 CAS 在同一事务中
  领取并结束本地取消身份；不占数据 writer 配额，不取得远端租约，不创建、重开或删除 partial。
  SQLite 原有 schema/代次约束保持，无需迁移；取消期间的操作纳入退出排空。
- 账号切换、撤权和退出会摘除等待项，取消原任务并等待实际清理；旧回调不能派发到新账号。
- 下载另存为仍只适用于单个普通文件。进程内暂停保留原有行为；列出记录、打开页面和重复提交历史草稿不自动开始下载。
- 收藏分组头改为轻量紧凑布局；Lucide 图标使用原生单色前景，随明暗、高对比与禁用状态着色。
