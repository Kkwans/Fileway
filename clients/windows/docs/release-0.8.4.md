# 栖卷 Windows 0.8.4

0.8.4 增加“按文件类型选择打开方式”，并保留稳定版内置 PDF 查看器。

## 本版完成

- 新增按文件类型配置打开方式：Markdown、文本/代码、图片、视频、音频、PDF、压缩包，共 7 类；入口在「工具 → 打开方式…」。
- 每一类可选「内置查看器」或「系统默认应用」；默认全部内置（PDF 也默认内置）。
- 选择系统默认应用时：先下载到默认下载目录，校验本地文件身份/大小后，再交给 Windows 默认应用打开（例如 Typora 打开 Markdown）；下载或校验失败会给出可区分提示。
- 偏好持久化到数据目录 `open-with.json`（原子写，不含凭据）；实测保存后重启/重新读取生效。
- 内置 PDF 继续使用 Windows 自带 `Windows.Data.Pdf` 引擎（逐页渲染、上一页/下一页、密码保护与页数上限处理），本版保持稳定版本不变。

## 已验证

- 打开方式对话框：7 个分类、默认值、保存后写入 `open-with.json`、主按钮在右。
