# Android 1.2.2 与 TV 0.2.0

手机侧栏新增「连接 TV」，支持局域网发现、扫码与二维码图片识别、持久配对、
独立设备授权及导航/输入/播放控制。无需另装遥控应用，范围为已经打开的栖卷 TV。

手机一键将当前账号授权给 TV；TV 保存自己的设备凭据，不复制手机密码或 JWT。
手机切换账号、断开遥控或关闭后，TV 保持独立登录与播放。需要切换 TV 来源时，
先在手机切换，再点击 TV 登录按钮。详见[手机遥控](tv-control.md)。

播放控制包括源时间进度、上下项、倍速、1% 粒度的软件音量、音轨及字幕。
TV 仍使用自己的播放器，具体格式受 TV 当前解码能力限制。

## 安装与验证边界

- 手机 1.2.2/code46：Android10/API29+，ARM64/x86_64，保留原签名与本机数据。
- TV 0.2.0/code4：Android9/API28+，ARM32/ARM64，保留独立 TV 签名与数据。
- 本次交付为签名 debug APK，未做 release 压缩；TV 尚未包含 FFmpeg 音频扩展，
  音频格式依赖系统解码器。手机保留既有 FFmpeg 媒体能力。
- 小米14上真实的独立手机/TV进程通过发现、屏幕QR解析、配对、独立授权、
  文件导航/搜索、自有视频播放控制、音轨解码器及外挂SRT状态、断线续播和TV重启恢复。
  最终手机侧栏触控打开遥控页、自动连接可信TV与两端同签名覆盖安装均通过。
- API28/x86 TV模拟器通过升级安装、原生遥控主机启动与QR显示。
  上述结果不是两台实体设备相机扫码、Q1投影仪声音/HDR、复杂ASS/PGS或长时性能验收。
- 当前 TV 侧栏、字体、播放器菜单及已有声音/字幕问题尚未全部解决，后续优先整改。
