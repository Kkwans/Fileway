# 栖卷 Windows 0.8.108

0.8.108 修复上传/下载详情“取消确认”时的双主按钮：确认框出现后，命令区的“暂停/继续”主按钮暂时隐藏，只保留“确认取消”一个蓝色主操作；返回或任务状态变化后恢复原主按钮。

## 本版完成

- 上传详情：`RenderUploadDetails` 在取消确认可见时清空命令区主按钮并禁用，只保留“关闭”；点击“继续上传”或任务不再可取消时恢复“暂停/继续”主按钮。`Cancel.Click` 立即重新渲染，避免进度刷新把主按钮重新加回。
- 下载详情采用同一逻辑；两处均以 `CancelConfirmation.Visibility` 作为唯一判定。
- 真实流程：上传 512 MB 文件 → 详情显示“正在上传 6 MB/512 MB” → 通过 UIA 触发“取消上传…” → 确认框出现时命令区只有“关闭”，唯一蓝色为“确认取消” → 确认后显示“上传已取消 / 服务器已确认取消”。
- 证据：修复前 `20261031-ui08107/screens/cancel-upload/upload-cancel-confirm.png`（“确认取消”和“暂停”两个蓝色按钮）；修复后 `20261031-ui08108/screens/cancel/upload-cancel-confirm.png`、`upload-cancelled.png`、`upload-active.png`。
