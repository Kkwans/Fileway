# TV 字幕选路与恢复

字幕和字体复用共享 `media-core`，不额外创建播放器，也不在调整字幕时重建视频
Surface。服务端声明 `sourceSubtitles` 表示可以读取源资源，不代表原生路径必须
关闭自己的字幕。

## 选路

- 原生播放优先使用 Media3 已解析且支持的轨道。MKV 的 ASS 数据、样式、字体、
  普通文字和 PGS 由现有 `MediaSubtitleExtractor` / `MediaSubtitleLayer` 提供。
- FFprobe stream index 与播放器轨道 ID 属于不同编号空间。只在同一绑定媒体内，
  格式、规范化语言、原始名称、默认与强制标记在两侧均唯一时关联；不根据列表
  顺序、轨道数量或显示名称单独猜测。
- 关联不确定时读取受鉴权的原格式源字幕；SDR/HLS 仍从原片获取字幕与附件，
  使用原片时间，不默认烧录字幕或把 ASS 转为无样式文字。
- 当前媒体中已完整载入的源字幕可直接复选实际轨道。缓存身份包含原媒体身份，
  播放器代次结束后不能继续引用旧轨道 ID。

## 选择与恢复

`SubtitleIntent` 区分自动、关闭、源轨道、原生格式身份和外挂资源。请求意图与
确认生效的轨道分别管理；切换音视频路径时恢复该语义选择，不重新猜第几个轨道。
外挂记录内容版本和语言轨道 key，多语言字幕不能在恢复时退回第一种语言。
同一路径的不同导入版本分别保留其实际内容摘要。

请求绑定会话、控制媒体代次、播放器代次和字幕选择代次。关闭、换字幕、换媒体
及换来源都会使旧结果失效。读取中的本地 broker 租约随取消撤销，防止清理工作
必须等待阻塞读取的网络超时；完成导入的资源由媒体控制器持有并统一释放。

字幕准备状态覆盖原生轨道等待、附件读取和导入。错误不覆盖续播保存状态；TV
与手机显示准备状态及可重试的错误，不给无法计算总量的操作伪造百分比。

普通文字的字体、字号和位置使用共享文字外观设置。ASS 默认保留片源样式；
位图字幕的字形已经包含在图像内，不能宣称修改位图字体。

这些是实现契约，不是所有片源、设备或复杂字幕的验收声明。实际支持边界随
发布包的兼容说明交付，物理 HDR、声音和投影阅读效果需要各自的真机证据。
