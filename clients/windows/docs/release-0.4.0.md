# 栖卷 Windows 0.4.0

完整影音里程碑；本地未签名预览，供用户人工安装验收。

## 本版新增

- **选集与自动连播**：播放器更多菜单"选集"列出同目录媒体（当前项高亮、按名称排序、≤50、
  不递归），选定后在同一窗口换源（loadfile replace，先取得新租约再释放旧租约）；播放结束
  自动播放排序的下一集（远端→远端、每集仅尝试一次、失败不打断）。下载来源会话不提供换源。
- **远端同目录外挂字幕**："从服务器加载字幕"有界列举同目录字幕文件（同名主干优先），选定
  才取得租约流式 sub-add；本地媒体不提供该入口。
- **兼容画质（真实 HLS 转码）**："兼容画质"菜单：原画直连或 2160p/1080p/720p/480p。非原画
  经服务端 /media/hls 任务在 streamable 后以租约子路径流式换源；被取代任务与窗口关闭自动
  取消。不做假画质列表。共享传输层为此新增 additive 能力：`/media/hls/` 端点族放行与
  租约子路径转发（Android 无行为变化）。
- **音频播放**：常见音频格式（mp3/flac/wav/aac/ogg/opus/m4a/wma/ape/mka/aiff 与 audio/*）
  经同一播放器打开，HUD/进度/倍速/选集连播全复用；下载任务音频可播放。
- **音量 0–200% 软件增幅**：100% 即系统混音器电平，100–200% 为引擎侧 softvol 增益，与
  Windows 系统音量完全独立；超过 100% 百分比用强调色提示，可能削波属软件增益固有特性。
- **SMTC 系统媒体键**：硬件播放/暂停/停止键与 Windows 媒体浮层控制播放器，含上一集/下一集
  （按选集排序启用）；标题与播放状态实时同步到系统浮层；不触碰系统音量。
- **小窗模式**：更多菜单一键进入右下角置顶 384×216 小窗，播放/HUD/媒体键持续工作；再次
  点击恢复记忆尺寸；全屏接管并在退出后还原小窗状态。

## 边界

- 兼容画质的转码进度展示与音轨/内挂字幕流选择（服务端已支持参数）保持为后续切片；
  直连播放始终优先，不自动降级到转码。
- 选集/字幕/画质列举均不递归、有上限；远端目录结构变化按 SourceChanged 呈现。
- 自动连播仅在远端媒体之间；下载边下边播与历史重开的既有边界（0.3.7）不变。
