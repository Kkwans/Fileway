# 栖卷 Windows 0.8.26

0.8.26 让“主按钮右置”幂等：只在主按钮确实位于关闭按钮左侧时交换，避免把本来就正确的对话框反向挪错。

## 本版完成

- `DialogOrdering` 增加方向判断：主按钮列号大于关闭按钮列号（或堆叠布局中已在右侧）时不再交换。
- 实机复核两个两点按钮对话框：打开方式（取消左 / 保存在右）、重命名（取消左 / 确定在右）均保持正确；此前从菜单打开时会因首帧找不到按钮而失败的问题仍由延迟重试覆盖。
