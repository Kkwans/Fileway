# 栖卷 Windows 0.3.3

本次针对文件管理界面的选择组件、通知、图标和空间层次统一处理；保留已认可的播放器外观。

| 范围 | 实现变化 |
| --- | --- |
| 下拉选择 | 统一使用原生 ComboBox 输入与焦点行为，移除 ChoiceBox 的鼠标/键盘拦截和独立窗口；类型/布局恢复普通 Flyout，不再激活另一个窗口 |
| 弹层样式 | ComboBox、菜单、类型/布局和提示使用统一材质与明暗配色；类型/布局按内容收紧至 136 DIP；选中项采用低饱和底色 |
| 图标 | 切换 Lucide 原始图形，提供明暗图标；文件与操作使用同一体系。原始 SVG、许可证、固定提交与可复现导入脚本一并保留，未重新手绘图标 |
| 顶栏与侧栏 | 默认稳定的中性雾灰，不随窗口失焦改变；可选择实时桌面模糊或壁纸取色；中性底色可选雾灰、暖灰、冷灰或自定义取色，自动适配明暗可读性；同时修正深色文件内容层的默认资源 |
| 路径导航 | 导航按钮、路径和搜索框垂直居中，面包屑使用正确的 BreadcrumbBarItem 容器 |
| 收藏/标签 | 标题、数量与常用操作合并为紧凑顶行；去除重复命令行、重复区块标题、常驻成功条；资源名称与原位置分开显示，保留真实色点与右键操作 |
| 通知 | 各页面复用可关闭、按用户偏好自动消失的模糊浮层，默认 5 秒；通知不再占据列表行高，操作按钮和未知结果核实入口保留 |
| 相邻页面 | 任务操作左对齐，正常状态不持续展示技术性权限说明；搜索和最近访问去除冗余说明；存储页提示同步使用浮层 |

设置入口：工具菜单中的“外观与交互”。背景修改立即生效，不修改 Windows 全局设置。
透明效果不可用、高对比或系统回退时使用可读的实色表面，不强制开启系统透明。

按用户约定，不新增或运行测试套件；开发完成后进行必要的编译、打包与启动检查。
完整原生视觉、选择交互、背景切换和人工体验仍由用户验收，不把编译通过当作视觉通过。
播放器退出 CFG 风险、跨重启下载续传、完整边下边播等既有未完成项保持。
