# Offline native Markdown mathematics

- Engine: official `mathjax@4.1.3`, https://github.com/mathjax/MathJax/releases/tag/4.1.3 . Apache-2.0; complete license in `MathJax-Apache-2.0.txt`.
- SVG font data: official `@mathjax/mathjax-newcm-font@4.1.3`. Its published `package.json` declares Apache-2.0; the exact declaration is preserved with the assets. The formal font package contains no separate LICENSE or NOTICE file. This application ships its generated SVG path data, not New Computer Modern OTF/TTF/WOFF files. See `MathJax-fonts-NOTICES.txt` for attribution and the distinction from the original font distribution.
- Bundled mhchem parser: copyright (c) 2015–2023 Martin Hensel, Apache-2.0. Its original notice remains verbatim in `mathjax/input/tex/extensions/mhchem.js` and is reproduced in `MathJax-fonts-NOTICES.txt`.
- Native SVG: `io.coil-kt.coil3:coil-svg:3.6.3`, Apache-2.0 (existing `coil-APACHE-2.0.txt`); its Android dependency `com.caverock:androidsvg-aar:1.4` is Apache-2.0, copyright Paul LeBeau. No custom SVG parser is added.
- Assets: `app/src/main/assets/markdown-math/vendor-manifest.json` records every exact upstream path, package, formal archive URL, SHA-512 SRI, byte size and SHA-256. `scripts/vendor-markdown-math.py --cache-dir <explicit-private-evidence-directory> --list`, then `--write`, verifies and copies only this allowlist; no Node installation or build. It refuses unequal existing files.
- Enabled TeX packages: base, ams, newcommand, configmacros, color, boldsymbol, mathtools, cancel, enclose, mhchem, textmacros, braket, bbox, amscd, upgreek. `require`, autoload, HTML/URL/setoptions extensions and menus/speech workers are not shipped or activated.
- Rendering: one isolated local WebView per document generation converts TeX to standalone SVG; native Markdown text, selection, images and links remain native. The WebView never displays document HTML, navigates externally, uses a JavaScript bridge or clears shared browser data. Dynamic SVG font chunks are served from the fixed local origin. Unknown Unicode can use native system text fallback; not every codepoint is a path.
- Native sizing: pass explicit em/ex/container pixels, export px SVG size plus ascent/depth, and align against the actual Compose text line baseline. Oversized inline formulas scale as a unit to the text width; standalone blocks can scroll horizontally. The original TeX remains the inline alternate text and selectable block source.
- Safety: 256 formulas, 16 Ki UTF-16 code units per formula, 256 Ki code units per document; 1000 macro substitutions/array template substitutions, 16 Ki internal TeX buffer; 512 KiB SVG each, 8 MiB SVG per document, 8192px side/4 Mi pixels per formula, and one 30s document budget. These bounds are not a guarantee of a 32MiB total browser/native heap. Cancellation only destroys the owned WebView and rejects old results, never terminates a shared renderer process.
- Compatibility: Android API29/JDK17 remain unchanged. MathJax is a fixed browser asset, not JVM bytecode; actual API29 WebView/provider behavior and native SVG output require the module's Android gate. Unsupported engine/provider behavior keeps TeX plus a visible fixed error.
- Current scope: JBM identifies `$...$`/`$$...$$` nodes. This adapter does not claim new `\(...\)` delimiter recognition, automatic equation numbering or document cross-reference navigation. Those require parser/navigation integration rather than a homegrown TeX parser.
