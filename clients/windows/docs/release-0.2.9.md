# 栖卷 Windows 0.2.9

供用户人工验收的 Windows 11 x64 未签名本地预览。基于 0.2.8 增量交付，
不表示 0.3 传输里程碑或完整 Windows 产品目标已完成。

## 本版变化

- 详细网格、紧凑网格、无界网格共用的图标/缩略图、文件名和辅助信息统一居中。
  长文件名保留两行省略和悬停完整名称，列表视图保留按列排列。
- 修复共享无边框逻辑拦截未订阅窗口的关闭消息，图片窗口恢复默认关闭路径。
  主窗口进入关闭准备后不再因布局通知重建非客户区输入区域。
- 支持条件源版本的服务器可为活动下载播放提供版本绑定的临时 Range 读取。
  读取前后观察、租约和响应头必须匹配；条件失败时拒绝发布未核实的读取数据。
  这项能力需要服务器提供 conditionalDownloadV1；旧服务器继续走原有读取路径。
- 安装包版本默认从实际应用程序集读取，显式版本与应用不一致时停止打包，
  避免安装程序版本和安装后的程序版本不同。
- 保留 0.2.8 的下载重新预检/新任务重试，以及既有登录恢复、文件浏览、收藏/标签、
  搜索、任务、回收恢复、复制/剪切/粘贴、缓存、图片和 Screenbox 风格播放器。

## 已知限制

- 应用退出仍存在未解决的 CFG fast-fail 崩溃。关闭流程改动尚不能证明根因修复。
  最新调查指向消息 hook 的失效回调，注册者与释放方仍需对应证据确认。
- 下载执行仍为 fresh-only；不支持旧 partial 续传、启动自动恢复或目录批次。
  播放器按需 Range 读取不会增加已保存下载进度，也不保证离线可播放时间。
- 通用 MP4/MKV、大文件任意跳转、HDR/多屏和安装升级等体验由用户人工验收。
- 本包未签名；完整分发许可证审查与正式公开发布门槛尚未关闭。

本批按用户要求只进行生成安装包所需的构建与打包，不运行新增自动化测试或电脑验收。
此前 CI 和固定夹具证据的范围保持原记录，不据此宣称本版人工验收通过。
