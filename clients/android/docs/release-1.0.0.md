# 栖卷 · Fileway Android 1.0.0

栖卷的首个 Android 正式版：连接 Fileway 服务器，在手机上管理文件、查看图片与文档、播放音视频，并集中处理传输和后台任务。

## 主要变化

- 统一文件、最近、资料和任务页面的列表操作：单击详情、长按多选，可打开的文件和目录双击打开。
- 最近播放与最近访问支持全选、批量删除和清空；保留文件与记录的操作边界。
- 重整详情、字幕调整和任务面板，采用统一的图标操作、对齐、圆角和实时局部模糊材质；浅色与深色分别适配。
- 精修播放器全屏控件、锁定交互、字幕来源与字体预览、自定义与预设倍速、目录播放列表及最近播放入口。
- 优化下载、上传、后台任务与操作历史的布局，展示真实创建时间、运行耗时与平均速度；运行耗时不计暂停和离线时间。
- 整理图片、缩略图和视频缓存设置；文件详情展示可用的创建时间，并支持按需统计目录大小。
- 保留文件搜索、收藏与标签、回收站、归档预览、账户管理及应用内更新等既有能力。

## 安装与兼容

- Android 10及以上，通用APK包含arm64-v8a和x86_64。
- 正式release构建：`1.0.0` / versionCode **38**，Room **9**。
- 沿用包名 `io.github.kkwans.nasfilebrowser` 与原签名，覆盖安装保留已有账户、目录、下载记录和本机设置。
- 最近记录批量删除需配套 Fileway 服务端 `2026.10.25-v1` 或更新版本。服务器配置与权限规则继续由各实例管理。
- 系统安装器会执行最终的签名和兼容性校验。发布资产提供确切源码提交及 `SHA256SUMS`。

原生媒体能力受具体设备、解码器和媒体格式影响；正式发布不等于已验证所有设备与格式组合。

## 第三方组件

原生播放使用Media3、FFmpeg音频与libass字幕；构建和第三方许可见 [Android构建说明](../README.md)及 [原生媒体配方](ffmpeg-audio-probe.md)。
