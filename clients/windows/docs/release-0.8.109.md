# 栖卷 Windows 0.8.109

0.8.109 收敛上传/下载详情的浮层与取消排版：详情弹窗打开时隐藏同一任务右下角的重复浮层；关闭弹窗后恢复，避免浮层从模态遮罩后透出、与详情争夺注意力。取消确认出现时直接收起“取消上传…”按钮，不再留下一个变灰的失效按钮占据竖向空间。任务浮层改为“文件名 / 指标”两行，512 MB 之类的数值与单位不再被拆到两行。

## 本版完成

- 上传详情：`RenderUploadNotice` 在 `_uploadDialog` 存在时关闭 `UploadNotice` 并跳过渲染；打开详情、关闭详情均立即重渲染。关闭后重置浮层的去重键，使同一上传阶段也能重新显示浮层，不会因弹窗期间超时而永久丢失任务反馈。下载详情采用同一逻辑。
- 浮层排版：上传/下载浮层消息由 `{文件名} · {指标}` 改为 `{文件名}\n{指标}`，文件名与“服务器已确认 50 MB / 512 MB”各占一行，单位不拆行；状态标题、指标、任务动作保持原有层级。
- 取消确认：确认卡可见时 `Cancel` 由“禁用”改为 `Collapsed`，确认卡上移，作为唯一取消入口；“继续上传 / 确认取消”在命令执行期间同时禁用，防止操作中途把确认卡藏起来。
- 真实流程：上传 512 MB 文件 → 详情自动打开（无重复浮层）→ 关闭详情（浮层恢复，两行排版）→ 从浮层重新打开（浮层再次隐藏）→ 取消上传（按钮收起）→ 确认取消 → “上传已取消 / 服务器已确认取消”。
- 证据：`20261031-ui08109/screens/upload-active.png`、`upload-toast.png`、`upload-reopened.png`、`upload-cancel-confirm.png`、`upload-cancelled.png`；UIA 同时确认取消确认状态下 `取消上传…` 已不在按钮树中，详情打开时 `查看上传` 不可见。
