# 栖卷 Windows 0.8.1

0.8.0 实机验收后的功能修复候选，本地未签名交付。范围为功能正确性、数据安全和必要的操作反馈；整体 UI 重做另行规划。

连接库升级至 schema 8，迁移前自动备份。旧客户端不能直接读取升级后的库；恢复旧版本需依据备份处理，见 [本地连接数据](local-data.md)。旧配置没有加密密码库时，首次恢复可能需要输入一次密码并重新选择保持登录。

## 功能修复

- 文本和 Markdown 正确加载正文；未加载状态禁止保存，保存后更新放弃编辑的基线。CSV 展示全部列并支持横向滚动，文件菜单正确开放已有预览类型。
- 修复连接、登出及收藏上下文重绑的重入崩溃。保持登录时使用独立 DPAPI 密码库恢复失效令牌，并恢复上次主浏览目录；关闭保持登录、登出和忘记连接清理对应凭据及导航状态。
- 合并重复的连接操作，保证新建连接及最小窗口下的关键选项可用，准确呈现认证、网络和本地存储错误，冷启动应用已保存的语言。
- 下载租约和最终校验绑定已确认的源版本。正常退出保留可续传 partial；保存意图失败仍排空 writer。修复活动下载的播放入口和旧任务排空失败时的错误分类。
- 存储分析、重复扫描与用户管理入口可达，离开再进入和异步回调绑定各自上下文。修复分析提交死锁、成功响应误报、清理结果轮询与新用户创建后的列表刷新。
- 管理员角色调整保留其余当前权限，包括 Windows 未编辑的分享权限；锁定、密码和删除操作维持各自语义。
- 布局及图标尺寸切换在面板重建后立即生效；关闭到托盘移除任务栏入口，托盘恢复重新显示原窗口。
- 安装器允许恢复版本目录已缺失的陈旧注册，保留有效安装和已有目录；只更新仍属于旧安装且未被编辑的快捷方式。
- 修复媒体音量选项、文件打开错误分类及播放后退出崩溃。播放器显式选择系统 OpenGL，仍使用既定 D3D11 输出并正常释放引用；归属证据见 [退出分析](player-exit-cfg-analysis.md)。

## 已完成验证

- Release Go Host、Windows 应用与 publish：0 警告、0 错误。
- 既有 Infrastructure 全套：2030/2030，0 失败、0 跳过。迁移成功路径的旧夹具按真实 schema 1–5 边界重建，继续验证 WAL、备份恢复、元数据、完整性与事务回滚；当前 schema 为 8。
- 原生定向回归覆盖文本保存与哈希、CSV、凭据恢复和清理、下载哈希与暂停/重启续传、存储分析、重复清理及恢复、一次性用户管理、收藏分组 CRUD、五种布局和托盘恢复。
- 无调试器的 H264、HEVC、ASS 播放后退出，以及保留播放器直接退出主窗，应用退出码均为 0。
- 实际 0.8.1 安装 payload 的哈希、全新连接、窗口移动/缩放/最大化/最小化/恢复、远端 H264 播放，以及应用和 Go Host 双零退出已通过。
- 完整安装包的新装、运行中拒绝安装、正常退出请求、有效同版本保护、缺失目录自修复与卸载通过；额外文件、其他版本和原有 0.8.0 注册保留。

## 仍需验收与延期

- 真实桌面拖放尚未执行：驱动返回 `foreground_not_target`，等待解锁且源窗口处于前台。活跃上传的取消/重启干预、活跃服务器文件任务的取消/重试仍无完整原生证据。
- 当前主测试账号为管理员，权限不足场景保持未测试，不计为缺陷。
- 冷启动连接页闪现疑点仍未复现；前进导航按既定决定延期。音量按钮等视觉效果等待用户验收，整体 UI 改造后置。
- 完整代理、换网、HDR/多屏/DPI、全量英文本地化等延期范围沿用 [0.8.0](release-0.8.0.md)。历史 progressive 堆写坏观察没有完整堆栈，本版不据此宣称已关闭。

本包用于本地验收；未替换签名身份、合并 main、打 tag 或发布公开 Release。媒体再分发许可完整性仍遵循既有 G5 门槛。
