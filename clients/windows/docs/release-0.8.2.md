# 栖卷 Windows 0.8.2

0.8.2 是 UI/UX 重构的第一个可验收候选，重点在查看器、详情面板和全局视觉规范。功能正确性沿用 0.8.1；本版不改变连接、上传下载与播放协议。

## 本版完成

- 新增统一设计系统：语义色板、圆角、字号、毛玻璃与自绘主/次/图标按钮；不再直接使用原生 Button 外观。
- 图片查看器重做：全黑沉浸画布、自动隐藏的顶部信息条、底部毛玻璃工具栏与左右翻页；滚轮以光标为中心缩放、双击切换适应/放大、拖拽平移、方向键翻页、0 适应、1 原图、Esc 关闭。
- 文本 / Markdown / CSV 阅读器重做：阅读器式工具栏、780px 可读栏宽、底部状态栏；标题层级/正文行高/列表/引用/行内代码/代码块（横向滚动）重新排版；CSV 表格显示全部列并横向滚动；状态文案改为准确的“可编辑/只读”。
- 压缩包浏览重做：目录层级导航与面包屑、文件夹/文件图标、大小列、多选、解压选中/全部解压、进度与结果横幅。
- 修复解压无法使用：确认对话框缺少 `XamlRoot`，`ShowAsync` 直接抛出并被吞掉，导致永远弹不出确认框。
- 文件详情面板重做：圆角方形图标容器（修复圆形裁切）、信息分组、传输/管理两组带文字的图标磁贴、主操作右置。
- 详情面板拖拽语义修正：改为左键按住并移动超过 4px 才开始移动、松手立即停止；单击不再触发移动。
- 全局 ContentDialog 统一为 18px 圆角与自绘主/次按钮；压缩包确认框实现“主按钮在右”（RTL 命令区 + LTR 内容）。
- 文件夹上传在目录树提交后立即刷新，不必等待最后一个文件完成。
- 复制/移动提交后增加后台任务轮询，完成时自动刷新来源目录并提供结果通知（实现已接入，端到端验证见“未完成”）。
