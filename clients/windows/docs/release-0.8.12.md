# 栖卷 Windows 0.8.12

0.8.12 重排连接页：未连接时整窗为欢迎页，左侧品牌说明、右侧表单卡片，所有操作回到同一张卡内。

## 本版完成

- 连接页改为整窗欢迎布局：隐藏导航侧栏，内容为最大宽 1120 的两栏（左侧 34px 标题与三行能力说明，右侧 440px 表单卡片）；窗口 < 1000 时自动收起品牌栏。
- 卡片使用 18px 圆角、`FwSurfaceBrush` 表面、1px 描边、26px 内边距；保持登录、连接按钮、取消/返回全部并入卡片，左右边缘与输入框严格对齐（不再有比卡片更宽的独立底栏）。
- 服务器地址、名称、用户名、密码统一使用 `FwTextBoxStyle` / `FwPasswordBoxStyle`；输入框、下拉与选项统一左对齐并显式锁定文本左对齐；密码框补齐“输入密码”占位提示。
- 修复固定高度导致带标题输入框被裁切的问题（改为最小高度 34，随内容增高）。
- 主操作右侧：恢复已保存登录为主按钮居右、忘记连接居左；连接失败态的取消按钮改用统一次级样式。
- 键盘路径：服务器、名称、用户名、密码任一输入框内按 Enter 直接发起连接（按钮不可用时忽略）；浏览区新增 Backspace 返回上级（与 Alt+↑ 一致）。
- PDF 查看器去原生样式：原生 CommandBar/SymbolIcon 换成底部浮动玻璃药丸工具栏（Lucide 图标），页面区改为 `FwCanvasBrush` 圆角画布；“适应窗口”按视口宽度计算缩放（此前与“100%”执行同一动作），首页/末页禁用对应翻页按钮，左右方向键翻页；PDF 渲染路径未改。
- 设计契约同步：`DESIGN.md` 记录连接页布局规则；`local-data.md` 修正密码存储说明（口令不写入 SQLite，另存 DPAPI 凭据库）。
