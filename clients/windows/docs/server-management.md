# Windows 服务器管理

设置页仅在会话具备对应权限时显示服务器管理入口。全局设置与用户管理要求管理员权限；
分享管理要求分享和下载权限。服务端决定分享范围：管理员查看全服分享，其他用户查看自己创建的分享。
设置页的用户入口打开存储工具已有的用户管理页。

全局设置通过既有 `GET/PUT /api/settings` 读写。写前重读并比对快照，在当前完整文档上应用改动，
保留客户端不认识的字段。服务器不提供条件写入，因此重读只能识别提交前已经发生的冲突。
写入结果不明时只做有界读回，匹配编辑项才显示已保存；否则要求重新读取，应用不会重发。
用户权限、范围、命令白名单和规则沿用 `/api/users/{id}` 的 `which` 部分写入，密码认证按服务端契约确认管理员身份。
命令配置不会在客户端执行，也不会改变服务端的启动能力。

文件夹详情通过与 Web 相同的 `/api/resources/recursive` 统计当前账号可见的文件、子目录与字节数。
不计当前目录本身，不用 `/api/usage` 的卷容量代替目录大小。读取有界，可取消；更换选择或关闭详情不保留旧结果。
Windows 服务端应使用包含递归路径分隔符修复的版本，避免旧版服务端漏计子目录内容。
