# 栖卷 Windows 0.3.1

本次是 UI/UX 与下载、回收站交互增量，保留已认可的 Screenbox 播放器样式。
按用户要求只进行交付必需的 Release/x64 编译与打包，不新增或运行测试，不进行原生体验验收。
以下为代码实现范围；视觉效果、实际播放和文件操作由用户人工验收，不能视为已经通过。

## 明确边界

- 下载暂停只适用于当前进程持有的活动下载：保留原 HTTP 响应、执行代次与文件句柄，暂停时 flush 后记录可读偏移；继续不重新打开 partial，不发起新 GET。
  长时间暂停后服务器可能关闭连接，此时安全失败并保留原有“重新下载（新任务）”流程。它不是 Range 断点续传，也不是退出后自动恢复。
- 删除活动任务先取消并排空写入和播放读取；删除完成的本地文件需要用户另行勾选，并验证卷、文件身份与目录归属。
  文件不属于原任务、仍有未知结果或删除失败时保留任务记录，不以路径直接删除；不删除 NAS 原文件。
- 字幕黑边策略依赖真实画面和窗口比例。图像字幕保留原始图像尺寸，采用位置偏移；不能保证任意图像字幕画布都能自动完整放入黑边。
  ASS 的显式坐标、动画和排版可能限制位置调节；保留样式不会自动清除影片特效标签。
  mpv 对超过 100 的文本位置存在裁切限制，因此此范围主要用于图像字幕；文本优先使用黑边边距。
  依据：[mpv 字幕选项](https://mpv.io/manual/stable/#subtitles)。
- 缓冲百分比来自 mpv 的 `cache-buffering-state`，不是整片下载百分比，也不是可播放时间比例。
- 播放器退出 CFG / C0000409 的既有风险仍未关闭；本版本不宣称已修复或稳定验收通过。
- 批量/目录传输、下载 Range 续传、重启恢复、完整边下边播及历史完成下载重开仍在后续路线，不因版本号递增视为完成。
- 安装包为本地未签名预览；不执行 main 合并、NAS 部署或公开发布。
