# 栖卷 Windows 0.8.10

0.8.10 为文件网格加入自定义容器模板，选中/悬停状态真正可见，并完成工具栏按钮的统一悬停反馈。

## 本版完成

- 新增 `FwGridViewItemStyle`：12px 圆角、主题表面、1px 描边、4px 外边距；不再依赖默认容器模板（默认模板会忽略 Background）。
- 选中态改为半透明强调底 + 左侧 3px 强调条，深色文字仍可读；悬停/按下使用统一的次级填充。
- 键盘焦点环独立绘制，禁用态统一 40% 透明度。
- 实测截图（选中 archive.zip）：`screens/ui-browser/browser-restyle-selected-123725.png`。
- 说明：卡片底色与主界面背景在浅色主题下非常接近，主要靠 1px 描边和选中强调区分；深色主题下对比更明显。
