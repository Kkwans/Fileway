# Windows 连接方式

连接档案可选择系统网络、系统 Tailscale 或内嵌 Tailscale。系统模式使用 Windows 现有路由，
用户先在系统 Tailscale 客户端登录；栖卷不启停系统服务。更换连接方式会生成新的连接来源标识，
因此不会继承另一条路由的会话和传输授权。

内嵌模式使用共享 Go 核心的 tsnet 节点。用户启动后在浏览器完成 Tailscale 授权，必要时等待
管理员批准，栖卷显示节点状态。内嵌连接经由严格的 Tailnet 拨号器，不回退到 Windows 的直接网络。
已批准的子网路由可以通过内嵌节点使用。停止或注销内嵌设备会关闭它的会话，
不删除已保存的服务器账号和凭据。

节点状态由共享核心加密，数据密钥由当前 Windows 用户的 DPAPI 包装，保存在客户端数据目录下
单独的私有目录。密钥丢失或身份损坏时保留原文件并提示，不静默生成替代身份。
内嵌授权只在用户点击时打开经过检查的 Tailscale HTTPS 登录页；链接、节点状态与 Tailnet 地址不写入诊断。
