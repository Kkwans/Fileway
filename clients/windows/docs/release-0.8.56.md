# 栖卷 Windows 0.8.56

0.8.56 修复文件网格在 1180 宽窗口下最后一列贴近/溢出右边缘的问题：`ItemsWrapGrid` 计算列数时没有计入 `GridViewItem` 的 4px 外边距，本版从单元宽度中扣除该边距。

## 本版完成

- `UpdateGridMetrics` 统一把 `ItemWidth` 扣除左右各 4px 外边距，覆盖详细网格、紧凑网格、无界网格和紧凑列表。
- 1180×760 实拍：5 列完整显示，右侧恢复安全留白；1000×700 保持 4 列，无横向溢出。
- 不改变图标尺寸、卡片高度、选择/悬停样式或视图切换逻辑。
