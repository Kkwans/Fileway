# 栖卷 Windows 0.7.0

存储工具里程碑；本地未签名预览，供用户人工安装验收。

## 本版新增（0.6.x 后续 + 0.7 主体）

- **文本条件写入编辑**（0.6-d）：查看器编辑/保存/放弃与脏关闭确认；保存走服务端
  conditional PUT（同锁二次核实 + 同盘暂存发布），冲突 409 拒绝不覆盖；非 UTF-8 源
  保存前明示重写。host request 通道 additive 支持 `bodyBase64`。
- **本地打开**（0.6-e）：已完成下载经只读身份核实后交系统默认应用打开。
- **ZIP 包内浏览与选择性解压**（0.6-f）：≤64 MB 有界浏览（≤5000 条目），解压含
  zip-slip 防御、逐条目与 1 GB 预算、已存在目标跳过不覆盖、逐条结果列明。
- **PDF 查看**（0.6-g）：系统内置 Windows.Data.Pdf 引擎按需渲染，密码/页数上限诚实拒绝。
- **容量分析**（0.7-a）：侧栏"存储工具"消费服务端 /api/analysis/storage 任务，
  Windows 只呈现服务器数字；范围摘要、最大文件/目录 Top10、截断与跳过标注。
- **重复文件扫描与清理**（0.7-b）：同面板双标签，服务端扫描 → 分组渲染（保留建议/
  可回收字节）→ 逐组单选保留副本 → 确认后 cleanup 提交，全部走回收站可恢复、
  逐文件成功/跳过/失败结果列明；绝不直接删除，需要明确用户动作。

## 边界

- 存储工具完全消费服务端任务体系（Windows 不本地猜测大小/内容比对）；分析范围是
  服务器路径，由服务端权限校验。
- 清理只动所选组内未保留的副本且经回收站；不含分享/公共分享；任何清理需要明确的
  用户确认动作。
- 0.6 剩余小尾巴（包内条目临时打开、归档搜索）与 EPUB 保持在后续范围（EPUB 拟
  0.9 评估）。
