# 栖卷 Windows 0.8.83

0.8.83 集中修正主浏览页与工具区的排版：文件网格在所有布局模式下按可用宽度铺满、筛选栏右侧动作组回到统一右边界、文件任务筛选宽度收敛、搜索页操作右置、详细列表右列右对齐；连接表单补齐读屏名称。

## 本版完成

- 主浏览页网格改为流体列宽：按偏好卡片宽计算列数，再令 `ItemsWrapGrid.ItemWidth = 可用宽度 / 列数`。`ItemWidth` 本就包含 `GridViewItem` 的左右 4px 外边距，旧代码再扣 8 DIP 导致每列少 8、右端累积尾隙（1200 DIP 窗口实测约 100px）。
- 详细网格、紧凑网格、无界网格与紧凑列表（两列）全部铺满；1200×900、1500×1000、1800×1100、2400×1300 实拍复核，UIA 边界为卡片左缘距网格 6px、右缘距网格 6px（150% DPI）。
- 筛选栏右侧“新建/上传/下载”组移除遗留的 48 DIP 右缩进，与搜索框、底部状态栏使用同一右边界（1800 窗口 UIA 右缘均为 1816px）。
- 文件任务筛选：任务状态 380→220 DIP、任务类型 140→160 DIP，消除 570px 超宽下拉与过窄类型框。
- 搜索页“打开/取消/重新搜索”移到工具区右侧，活动进度留在左侧，与最近访问的“左提示、右操作”结构一致。
- 详细列表右列“大小 / 修改时间”及列头改为右对齐，与最近访问/搜索/文件任务的时间列一致。
- 连接表单 `服务器地址`、`连接名称（可选）`、`用户名`、`密码` 补 `AutomationProperties.Name`，读屏与自动化不再依赖占位文字。
