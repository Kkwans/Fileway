# 栖卷 Windows 0.8.75

0.8.75 修复「缓存与存储」对话框在最小窗口高度下顶边被裁的问题：滚动区高度 480→360 DIP，对话框在 1200×900 下保留上下边距，内容改为内部滚动。

## 本版完成

- 缓存与存储对话框内容滚动区 MaxHeight 480→360 DIP；1200×900 下对话框顶部不再贴到窗口边缘，上下各留约 65–68 DIP。
- 「缓存占用 / 当前生效 / 保存配置」内容在对话框内滚动，关闭/保存按钮固定在底部，不被推出窗口。
- 实机复核：工具菜单入口可正常打开对话框（此前该入口在部分测试数据根下不可用），关闭按钮初始焦点规则保持 0.8.62 行为。

## 已知问题

- 对话框内容较长时需要内部滚动；滚动条为系统悬浮样式，悬停/滚动时出现。
- 菜单项与 Expander 头部的键盘焦点仍使用 WinUI 系统矩形焦点视觉（内部模板，暂列系统语义例外）。
- 高对比度主题未系统走查（需调整系统设置，待用户同意）。
- 文件批次的批次卡实拍仍需真人选择文件夹；拖入/拖到文件夹/拖出仍需真人鼠标验证。
- PDF 沉浸式外壳的原生堆破坏未修复；真正内容级模糊需 Composition/Win2D。
