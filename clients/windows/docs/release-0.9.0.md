# 栖卷 Windows 0.9.0

Windows x64 本地未签名候选，候选源码为 `5576f553a58aeb9962a06d8b7d9d1d050cf633bd`，程序集文件版本为 `0.9.0.0`。

## 改动

- 增加应用更新检查和本机缓存图库，补齐服务器全局设置、分享与用户管理、文件夹统计以及内嵌 Tailscale 连接流程。
- 统一页头、空态、资源行、分段选择和通知，复用主题色、图标和焦点样式。设置适配宽窄窗，更新检查、图库刷新和存储分析主操作与对应内容同行。
- 文件搜索使用顶部浮层，输入筛选当前列表，按 Enter 搜索当前目录及子目录。最近访问保留原文件失效状态，原文件恢复后可从同一条记录打开。文件网格随 Windows 字号调整列数和高度，详细卡片的类型、大小和日期跨列对齐。
- 短反馈优先使用标题栏，保留清晰的操作入口和自动消失。放大系统文字时，传输中心保留记录状态与动作。弹窗和浮层提供实色、柔和模糊和高级毛玻璃，系统限制透明时回退至主题实色。
- 图片查看器使用自绘标题栏、动态取色、顶部工具和可调缩略图，支持滚轮缩放与键盘换图。Markdown 支持渲染态编辑及外部软件打开，代码预览支持语法着色与可选行号。ZIP 列表、表头及结果共用边界，解压结果紧接短列表。
- 文件夹上传保留目录层级，传输记录保留同名保护、断线续传和实际任务详情。播放器复验暂停后下一段、音频跳过、末段动作及全屏往返。
