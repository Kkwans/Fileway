## 当前交付批次

0.2.3 接通已经欠缺的收藏/分组、标签并按 Web 的侧栏快跳与五种视图纠正交互；将本地外挂字幕上限提高到
500 MB（500,000,000 bytes）。服务/数据专项已通过，纠正版原生验收尚未完成。
0.2.4 独立核心切片已实现服务端搜索、文件操作、回收恢复、own-only 任务、主动校验及持久操作核实。
核心与专项构建为 0 warnings / 0 errors；首次集中运行 234 项，修复后仅复测 6 个直接受影响模块的
116 项，全部通过（0 failure / 0 error / 0 skip），其余 118 项复用同轮未受影响的通过结果。
这些结果不代表 UI 集成、原生验收、真实服务器新旅程或 Android JNI 已通过，也不关闭完整 0.2/G 门槛。

现有浏览器框架正按用户已授权的十项要求重构，覆盖 40 DIP 布局、面包屑、可调整区域尺寸、侧栏、
上下文菜单及名称裁切等；该工作仍在实施，原生验收待测。搜索/写操作/任务等新服务的 UI 集成另行完成。
浏览偏好/最近访问等剩余事项继续保留；既有 0.2 范围不因增量包或优先顺序改变而删除。

每批统一执行相关构建、专项和真实原生旅程，先收集问题再集中修复复测；不重复回归无关模块。
只有本表必需项目都有实现/验证归属、原生切片用户验收及完整旅程通过，才关闭 0.2 里程碑。
