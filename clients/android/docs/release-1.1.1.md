# 栖卷 · Fileway Android 1.1.1

## 播放与字幕

- 字体选择明确区分“本次使用”和“设为默认”。默认字体跨视频与重启保留，单独设置字体不会保存当前临时字号、边距等外观调整。
- 多音轨优先识别非中文原声；缺少可靠原声标记时，依次选择非中文片源默认、英语和其他非中文音轨。仅中文或语言均未知时保留片源默认；手动选择及解码器切换恢复不会被自动策略覆盖。
- 长按倍速采用画面顶部的紧凑提示；亮度、音量和进度提示保持居中。统一修复提示窗口首次出现的位置与原生模糊层的直角背景，保留局部实时模糊。
- 改善进度缩略预览的图像尺寸、居中布局与快进快退图标；菜单背景延伸至导航手势区域，“接下来”列表复用半透明信息卡片材质。

## HDR 信息

- 区分片源标记、屏幕能力与实际输出。使用实际解码配置、待显示帧的色彩格式、首帧确认和系统 HDR 亮度报告判断可确认的输出状态。
- 确认杜比 HDR 路径时显示 `HDR · 杜比视界`；HDR10 回退不继续标成杜比视界。实际输出无法确认时不把片源标记当成激活状态；技术详情保留可用证据。
- 合并系统高频 HDR 亮度回调，过滤不可见的小数抖动，避免状态观察引起不必要的界面刷新。
- HDR 检测取决于 Android 版本和设备报告。截图会经过 SDR 映射，不能据此验收屏幕实际 HDR 亮度。特定杜比片源的色彩稳定性仍需进一步验证，不承诺已消除所有设备的色彩波动。

## 安装与兼容

- 正式 Release：**1.1.1 / versionCode 42**，Android 10及以上，包含 arm64-v8a 与 x86_64。
- 沿用原包名 `io.github.kkwans.nasfilebrowser`、签名和本机数据，直接覆盖安装；服务器 API 与 Room 数据库结构不变。
- ASS／SSA 保留作者样式，位图字幕不应用文字字体设置。旧版本已保存的字幕外观继续保留。
- 本轮未改变原生视频 Surface、解码选择策略或系统色彩设置，未加入截图循环模糊或强制 SDR 调色。
- 发布附带源码提交、构建信息与 SHA256SUMS；历史版本见 [1.1.0](release-1.1.0.md)。
