# 栖卷 Windows 0.8.80

0.8.80 调整「缓存与存储」对话框的信息顺序：可编辑设置移到只读诊断之前，打开对话框即可看到缓存根目录、容量与默认下载目录，不再需要先滚过占用统计。

## 本版完成

- 内容顺序改为：说明 → 当前生效 → 保存配置（缓存根目录/容量/下载目录/自动续传）→ 缓存占用与清理操作。
- 1200×900 下打开对话框即可看到缓存根目录、选择按钮和容量输入框；占用统计与清理按钮滚动查看，关闭/保存仍固定在底部。
- 无控件增删，仅重排 `StorageSettingsControl` 内容；保存按钮启用条件与字段状态逻辑保持不变。
