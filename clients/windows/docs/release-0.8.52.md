# 栖卷 Windows 0.8.52

0.8.52 对文本型页面做排版收敛：最近访问、搜索、文件任务与操作记录统一“左侧图标与主信息、右侧时间/摘要”的扫描路径，并把孤立在左侧的操作按钮收拢到页面工具区右侧。

## 本版完成

- **最近访问**：操作行改为左侧提示“选中记录后按 Enter 打开”，右侧依次放“打开”、加载环与刷新按钮，不再出现左侧孤立按钮；列表行改为 22px 类型图标 + 名称/路径/附加说明 + 右对齐访问时间。
- **搜索结果**：结果行改为图标 + 名称/路径 + 右对齐“类型/大小 · 修改时间”摘要，减少纵向堆叠和长行空白。
- **文件任务**：任务行保留名称、状态、进度，创建时间移到右侧；操作记录同样把时间移到右侧，列表行更短、更容易横向比较。
- **统一细节**：右对齐时间使用 tabular numerals；列表行圆角、1px 描边、悬停/选中语义沿用 `FwListViewItemStyle`，未新造容器样式。
- 设计契约补充：文本型列表的图标/主信息/时间列规则，以及页面操作收拢到工具区右侧的约束。
