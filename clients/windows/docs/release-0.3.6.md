# 栖卷 Windows 0.3.6

目录与批次传输里程碑；本地未签名预览，供用户人工安装验收。

## 本版新增

- **目录下载批次**：选中目录后先做有界递归枚举（≤1000 个文件、目录队列 ≤5000、逐目录
  收集失败并继续兄弟子树），Windows 非法名/保留名按规则映射并全路径去重；确认对话框展示
  总量、失败/跳过、截断与映射后的实际保存路径。确认后逐条目生成保留相对结构的计划
  （BatchId+Ordinal 批次身份，存储层唯一槽位防重复提交），并幂等创建已验证下载目录下的
  目标子目录树（既有层只验证不替换），随后走与 0.3.4 完全相同的 FIFO 队列与 0.3.5 续传。
- **文件夹上传批次**：上传入口改为文件/文件夹菜单；本地有界枚举（≤1000、跳过 reparse），
  逐级创建远端子目录（同名文件即冲突停止、绝不覆盖），按批次身份逐文件走既有 TUS 队列；
  单目录失败只跳过该子树，不毒化兄弟目录。
- **拖入上传**：浏览器文件区接受从资源管理器拖入；拖动时显示标题与高亮覆盖层，仅在有
  创建权限且就绪的目录上接受；松散文件合并一个确认对话框批量提交，文件夹复用树流程。
- **服务端 ZIP 归档导出**：多选或目录右键「下载为 ZIP」，经共享 bridge 的 additive
  archiveFiles/algo 参数取得一次性导出租约，流式保存到默认下载目录并按不覆盖规则发布。
  动态归档不建持久任务、不支持续传、不做假校验（长度未知、EOF 收束、失败清理自建
  partial），执行纳入账号/权限围栏与退出排空。
- **缺陷修复**：真实 Go host 的 lease 参数白名单遗漏 `sourceVersion`，此前条件下载/播放
  租约经真实 host 会被参数校验拒绝（既有回归使用进程内假 host 未暴露）；已补入白名单
  并连同归档参数一起放行。

## 边界

- 归档导出为一次性流：取消即停止并清理未完成临时文件；无总大小与百分比（不伪造）。
- 目录下载的预检冲突检查覆盖批次内同名与映射去重；与磁盘既有同名文件的冲突仍在执行时
  以不覆盖规则失败并逐项呈现。
- 拖入的 reparse 目录（junction/链接）不遍历；本地枚举上限与失败逐目录提示。
- 真实 NAS 的目录/批次/归档旅程由用户人工验收；不创建公开 Release/tag。
