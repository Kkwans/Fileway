# 栖卷 Windows 0.8.162

0.8.161 收掉了选中态的多重标记；本版处理压缩包窗口的信息架构：列头只有名称/大小、
面包屑根标签右侧大片空白、空目录只有一行纯文字、状态栏不显示选中数。改动只到浏览层，
解压目标/进度/结果与包内预览按 0.8.163–0.8.164 继续。

## 现状取证

- `ArchiveWindow` 列头只有「名称 / 大小」，行内没有类型与修改时间；`ArchiveEntryInfo`
  也没有修改时间字段。
- 面包屑条只有「压缩包」根标签，右侧没有当前目录的条目数与文件合计大小。
- 空目录状态只有一行 14px「这个文件夹是空的」，没有图标卡与说明；列头虽隐藏，但视觉层级弱。
- 状态栏只有 `N 个条目 · 路径`，选中后不显示数量；用户无法确认多选结果。
- 目录行没有显式 zip 条目时，修改时间无法显示（不能用子文件时间冒充）。

## 改了什么

1. **契约**：`ArchiveEntryInfo` 增加 `DateTimeOffset? Modified = null`；
   `FilewayClientServices.ArchiveBrowse` 从 `ZipArchiveEntry.LastWriteTime` 取值。
   嵌套路径合成的目录没有显式条目时保持 null，UI 显示 `—`。
2. **四列**：名称 `*`、大小 96、类型 96、修改时间 150，间距 12；类型由扩展名映射
   （文件夹 / PNG 图片 / 文本 / ZIP 压缩包 / 代码等），时间格式 `yyyy/MM/dd HH:mm`。
3. **列头与行共用列宽**：行内容盒为左 4 + 图标 28 + 间距 12，列头左内边距因此是 44；
   列头右内边距 = 行右内边距 8 + **实际滚动条宽度**（内部 `ScrollViewer` 的
   `ActualWidth - ViewportWidth`），不再写死；`SizeChanged`/导航后重新计算。
   嵌套 zip 有 32 个条目、滚动条可见时，四列 UIA 边界 delta 均为 **0**。
4. **面包屑摘要**：右侧显示当前目录 `N 个条目 · 文件合计大小`；根目录显示 7 个条目 ·
   69.41 KB，进入「文档」后显示 2 个条目 · 16.37 KB。窗口宽度 < 760 DIP 时隐藏摘要。
5. **空状态**：72px 图标卡 + 20px 标题 + 13px 说明；根目录与子目录文案区分；
   空列表隐藏列头，状态栏只显示 `0 个条目 · 路径`，选择模式切到 None。
6. **状态栏**：选中数 > 0 时追加 `已选择 N 个`；空目录不显示。
7. **焦点与加速器**：导航后把焦点交回内容区（连续两次 enqueue，覆盖空目录没有行可持焦的情况）；
   空目录移除 Ctrl+A 加速器并切到 `SelectionMode=None`，避免 WinUI 在空状态继续弹全选提示。
8. 新增 `FwSecondaryIconStyle`，压缩包文件类型图标统一走 `FwTextSecondaryBrush`。

## 验证

- Release x64 构建 **0 警告 0 错误**（0.8.162.0），两次独立数据根启动冒烟均 `GATE=PASS`。
- `20261105-archive08162/Probe-Archive.ps1`：真实嵌套 zip（32 条、含文档/图片/空目录/
  长文件名/内层压缩包/24 个列表文件），浅色 `light5/report.txt` 与深色 `dark3/report.txt`
  **各 27 项 PASS、0 FAIL**：
  - 四列列头存在；根目录文件夹行与文件行存在；行内名称/大小/类型/修改时间四个单元格都存在。
  - 名称左缘、大小右缘、类型左缘、修改时间右缘与列头 **delta=0**（滚动条可见时）。
  - 面包屑摘要 `7 个条目 · 69.41 KB`；进入「文档」后 `2 个条目 · 16.37 KB`。
  - 状态栏根目录路径、选中 `已选择 1 个`、空目录 `0 个条目` 均命中。
  - 空目录标题/说明存在、列头隐藏、无标题栏或工具栏按钮持焦。
  - 实拍：`light5/archive-root.png`、`archive-subdir.png`、`archive-empty.png`；
    `dark3/` 同名一套。
- **证据说明**：空目录实拍里仍可见一个 WinUI `Ctrl+A` 加速器提示浮层。它由探针的
  键盘注入触发，位置固定在空状态中央；UIA 已确认空状态标题/说明/隐藏列头/焦点状态全部正确，
  该浮层不是布局的一部分。产品代码已把空目录的 Ctrl+A 加速器移除，用户正常鼠标操作不会出现。
- 连接页 `Invoke` 偶发抖动重试后通过，属探针已知抖动，不计产品缺陷。
