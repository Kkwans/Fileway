# Windows 缓存与预加载

## 0.2.1 行为

远端主视频通过 `ICachedResourceLeaseProvider` 取得 Go 回环媒体租约；外挂字幕仍用普通租约。
本地完整文件不走网络缓存。UI 不读取服务器令牌或拼接媒体 URL。

播放器使用 mpv 内存预读：目标前读 30 秒，前向包预算 64 MiB、后向 16 MiB，实际范围受码率、
解复用器和网络限制。共享 Go 核心保留磁盘块，并至多预取一个相邻块；不等于全文件下载，
也不承诺无网冷启动。关闭播放先停止统计与读取，再释放引擎和租约。

时间轴使用 mpv `demuxer-cache-state.seekable-ranges` 的真实起止时间；保留不连续区间，
不把拖到第十分钟后的缓存终点涂成从零连续缓存，也不以字节比例推算播放时间。
磁盘存在的任意块不自动当作当前解复用器可播放的时间范围。

“预加载 x.xx MB/s”只计算主视频租约上游字节增量，按单调时钟每 500 ms 采样并做短窗口平均；
磁盘命中和 loopback 交付不计网络速度，无新增字节显示 0，未知/本地来源隐藏，关闭后不再更新。
字幕、其他媒体会话不混入该速率。MB/s 使用十进制一百万字节每秒。

## 目录与统一预算

本机存储设置持久化在 schema 2 的 SQLite 表中，包含缓存根、独立默认下载目录和总数据预算。
默认预算为 **5 GB = 5,000,000,000 字节**，范围为 0—1 TiB；0 关闭磁盘缓存，内存预读仍可使用。
缓存目录变更下次启动生效，当前与待生效配置分别显示，不自动搬移或删除旧数据。
容量可在同一活动目录应用；应用失败仍保留已确认保存的偏好，并显示待生效。
默认下载位置读取 Windows Downloads 已配置的位置；0.2.1 只保存偏好，下载功能另行交付。

Go 只管理所选根下的 `fileway-cache-v1/<账号哈希>/<资源哈希>/` 与可识别的块/临时文件。
下载目录不能位于该专用池内部。清理不递归到用户任意目录，不删除未知文件；按账号清理不删除
其他 owner 的数据，池级容量淘汰覆盖所有账号。
Windows 显式启用 managed 布局，Android 未指定的新字段保持原布局和调用兼容。

所有账号共用一份预算。写入和淘汰串行，在创建临时块前预留空间，统计已提交块和可识别临时块；
必要时淘汰最旧的磁盘块，包括仍可从源重新读取的活动资源块。预算不包括文件系统分配粒度、
目录元数据、未知文件或旧缓存根留下的数据。缩略图/原图加入后必须使用同一预算，不能各得 5 GB。

## 身份、授权与失败

资源键包含 AccountKey、opaque wirePath 和经认证读取的真实元数据；不信任调用者显示名或伪造版本。
HTTP ETag/Last-Modified 和长度参与块版本；缺少可用 HTTP 版本依据时增加会话隔离。
这些版本依据不冒充内容哈希。即使命中磁盘，仍先核验服务器授权；撤销会话后旧租约失效。

写盘失败不截断已取得的合法媒体数据，租约统计上报写失败，客户端每会话提示一次缓存不可用。
配置失败可退回普通流式租约，取消不能被伪装成成功降级。缓存不是用户下载的完整离线文件。

注销先退休会话并删除凭据，再清理当前池中该账号的数据；清理失败保留待办并明确报错。
仅缓存盘故障不阻塞其他账号；同一待办账号不能在失败重连时重新保存凭据。
目录切换后的旧根不自动迁移或删除，跨旧根清理登记、占用/清理界面留待后续缓存版本。
缓存数据未额外加密；目录访问权限和跨目录清理仍需完整发布门槛的专项验收。

## 验证边界

聚焦验证覆盖 SQLite/WAL 升级备份、设置与退出并发、缓存命中/速率归属、授权/撤销、
账号隔离、未知文件保护、多个账号的统一配额、关闭/预取取消和旧调用兼容。
CLI 测试与构建不等于原生时间轴、文件选择器、真实网络或磁盘故障视觉验收。
