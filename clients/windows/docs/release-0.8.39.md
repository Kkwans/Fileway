# 栖卷 Windows 0.8.39

0.8.39 修正文件夹整组上传的自动刷新频率：整批结束后只刷新一次来源目录。

## 本版完成

- `TryRefreshCompletedUpload` 对带 `UploadBatchInfo` 的任务先检查整批状态：同批仍有排队/上传/校验/发布/等待网络或认证的成员时跳过。
- 整批进入完成、取消、跳过、失败或需处理状态后，使用批次级去重（`_uploadBatchRefreshes`）只触发一次来源目录刷新，避免 1000 个文件的文件夹逐文件重载目录。
- 单文件上传（无批次）行为不变；切换账号/上下文时批次刷新记录随上传上下文一起清空。
- 无界面样式变化，本版不附带视觉截图。
