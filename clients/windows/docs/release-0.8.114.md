# 栖卷 Windows 0.8.114

0.8.114 修正空文件夹与空收藏标签的底部状态文案：0 个项目时只显示“0 个项目”，不再提示“已选择 0 个 · 双击或按 Enter 打开”。空目录本身已有“这个目录还没有文件 / 可以刷新目录…”空状态，底部不应再给不存在的操作提示。

## 本版完成

- 主浏览状态栏：`_rows.Count == 0` 时显示“0 个项目”；加载中仍显示“正在加载目录… · N 个项目”；有内容时保留“N 个项目 · 已选择 M 个 · 双击或按 Enter 打开”。
- 收藏与标签页：当前标签资源为 0 时同样只显示“0 个项目”，不再保留打开提示；标签已删除的说明保持不变。
- 证据：修复前 `20261031-ui08114/screens/empty-folder.png`（底部“0 个项目 · 已选择 0 个 · 双击或按 Enter 打开”）；修复后 `screens/after/empty-folder.png`（仅“0 个项目”）。收藏页菜单自动化在枚举弹层时阻塞，本轮未取得截图，改动为同一文案分支。
