# Android 媒体核心

手机和 TV 共用原生播放器、字幕层及媒体资源预算。各应用保留自己的页面、输入、
鉴权会话和媒体租约；本模块不保存账号或创建另一套播放器。

## 视频磁盘预缓存

`PlaybackStreamCache` 是可注入的独立能力。TV 通过 `TvVideoCache` 接入，手机默认
不启用。默认容量 2 GiB，设置范围 64 MiB–64 GiB；保留 128 MiB 实际磁盘余量，
存储不足时有效容量会低于设置值。容量包括已提交数据和当前写入预留。

- 前台只读缓存，缺失部分直接请求上游，不等后台写入锁；后台只有一个写入者，
  使用独立可取消的 OkHttp 连接，以最多 8 MiB 请求和 2 MiB 文件片段连续预读。
- 不保留旧的 75% 停止阈值。全是未读数据且已达上限时等待播放进展；优先回收
  已播片段，再回收退休播放代次和 seek 后不再需要的远端窗口，不循环删除未读
  数据来下载相同内容。缩容时从窗口远端回收，当前读取范围受保护。
- 原文件使用实际 `SeekMap` 确定已播字节及缓存时间，不用读取游标或 VBR 线性
  估算。缺少可用映射时保守保留数据；不伪造时间覆盖。HLS 使用真实片段时间，
  加上源片偏移，保留初始化资源，只请求同源资源及服务端当前已生成的片段。
- `prepare` 不切断正在播放的源；首个真实 `DataSource.open` 激活新代次。账号、
  源身份和转码任务参与缓存命名，另加每次打开的随机代次，避免跨账号复用。
- `stop` 取消后台工作，读写句柄关闭后删除该代次媒体缓存。旧读取未关闭时延后
  清理并报告状态，不删除正在使用的文件。`release` 排空后释放数据库和连接池；
  下次启动清理本组件目录中的孤儿，不清设置、账号、字体或其他缓存。

`PlaybackCacheState` 提供实际使用量、网络负载速度、源时间覆盖和错误状态。
TV 遥控快照的 `content.cache` 投影这些字段；旧手机可以忽略该可选字段。

相关聚焦检查位于手机测试 APK 的 `PlaybackStreamCacheTest`（真实 Range HTTP、
SimpleCache、隔离小容量预算），以及需自有影片和现有登录显式启用的
`TvCachePlaybackTest`。这些检查不替代低内存 TV、完整 2 GiB 或长播放验收。

## 渐进 PGS 源字幕

`ExternalPgs.IndexBuilder` 单遍读取追加型 SUP，完整文件的 `index` 也使用它。
`ProgressivePgsSource` 负责有界帧协议、完整性校验、受限磁盘 spool 和不可变前缀
快照；播放器控制器拥有账号、租约和选择代次，loader 不保存这些上下文。
`NativePlayer.importPgsStream` 在字幕覆盖当前源时间后可先显示前缀，最终验证成功
才提供完整外部身份。失败或取消会移除未验证轨道；快照持有文件直到最后读者关闭。

完整索引的 event metadata 使用自有临时 sidecar，内存只留时间和记录偏移数组；
随机 seek 不读取无关事件。当前事件仍使用同一 SUP、Media3、palette 和 crop 路径。
渐进阶段只保留不可变前缀；完成后转为磁盘索引，避免多个完整轨道累计耗尽 TV
的 16 MiB 索引预算。sidecar 上限 32 MiB，关闭或失败只删除本索引自建的文件；
原 SUP 的删除权继续由调用者或 spool 引用计数管理，不作为跨账号持久缓存。

视频预取与字幕请求共用 `CancellableHttpSources` 的实际 Call 生命周期管理，
同时覆盖响应体读取及取消后的重试，避免仅取消 OkHttp headers dispatcher。
`ProgressivePgsSourceTest` 覆盖分片、部分覆盖、真实位图、源偏移、取消与校验失败；
其私有源诊断用例需要显式配置，不将用户媒体放进测试 APK 或仓库。

## 源 ASS 和字体

`SourceSubtitleAsset` 提供可取消的有界临时文件读取，调用者取得返回文件的删除权。
`SourceSubtitleFonts` 最多同时准备两个文件，串行注册字体；字体阶段默认 20 秒，
失败附件独立处理并返回不完整状态。控制器负责租约、源身份、账号及代次检查，
并向用户保留真实缺失提示和重试入口。它们均不持久保存 URL、账号或字体缓存。

每个字体最多 32 MiB；`MediaResourcePolicy.assFontBytes` 控制同一媒体的总量，
手机默认 64 MiB，TV 32 MiB。原生 MKV 在分配前执行同一策略；字幕层按名称和
内容摘要去重后注册，避免原生与源接口重复计入。后到的字体仅重建 ASS renderer，
保留原 track、时钟及视频源。完整 PGS builder 也接受注入的索引预算。

## 源字幕资源会话

`SourceSubtitleAssets` 是调用方媒体打开代次内的有限磁盘资产池，合并相同读取、
预留在途资源预算、pin 活动文件、LRU 淘汰非活动文件。所有权由 `Lease.close()`
释放；关闭资产池取消未完成生产者，活动文件等最后读者关闭再删除。调用方必须
按服务、账号和源身份隔离实例，不将其作为跨登录的持久缓存。TV 用于完整源 ASS
及字体跨视频解码路径复用，手机默认路径不变。
