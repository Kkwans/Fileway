# 栖卷 · Fileway Android 1.1.0

## 播放体验

- 播放器采用封面取色的流动网格渐变背景，保留深色观看环境；暂停、后台和关闭系统动画时停止流动。操作区保持开放布局，背景延伸至状态栏与导航手势区域。
- 统一亮度、音量、横滑、进度预览和长按倍速反馈，使用窗口局部实时玻璃材质；低版本和系统不支持时提供清晰的材质降级。
- 新增 Android 系统画中画，默认手动开启；可在设置中启用播放时自动进入，默认关闭。
- 视频信息展示容器格式及可获取的 HDR／杜比视界片源标记，修复最近播放入口的文件大小回填；没有后续视频时提供音轨与字幕卡片。

## 界面与整理

- 统一操作组的图标来源和动效，底部导航取消灰色点击波纹；多选在原位置进入与退出，保留顶部操作，分别提供全选和反选。
- 重整存储分析与重复文件报告，以摘要、紧凑排名及明确的清理边界展示结果。
- 精简详情和播放信息，修复从播放器打开所在目录的跳转；重写中英文 README 并提供真实界面截图。

## 安装与兼容

- Android 10及以上；通用APK包含 arm64-v8a 与 x86_64。
- 正式 Release：**1.1.0 / versionCode 40**；本机数据库仍为 Room 9。
- 沿用原包名 `io.github.kkwans.nasfilebrowser` 和签名，直接覆盖安装，保留账户、下载与本机设置。
- 流动网格渐变使用 Android 13+ AGSL，旧系统使用静态封面渐变；画中画和实时模糊取决于系统支持与设置。
- HDR／杜比视界信息来自片源元数据，不代表已验证所有设备的实际 HDR 输出。服务器 API 与数据库结构不变。
- 发布附带确切源码提交和 SHA256SUMS；原生媒体配方与第三方源码入口见 [Android 文档](../README.md)。

Animated icons by [Lordicon.com](https://lordicon.com/)。流动网格渐变复用 [Mirage / Paper Design shaders](https://github.com/AndroidPoet/mirage)，Apache 2.0。
