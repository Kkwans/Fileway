# 栖卷 Windows 产品路线

目标是覆盖 Fileway Web 与 Android **已存在的用户功能并集**，并提供合适的
Windows 原生交互。不是把 Go 接口存在、播放器引擎支持或页面按钮出现当作完成。
Android 的 SAF、前台通知与 APK 安装等平台机制，在 Windows 上以文件选择器、
原生任务/通知及安装升级等对应能力实现。

## 版本规则

- 使用普通增量版本 `0.2.0`、`0.2.1`、`0.2.5` 等；小版本既可增加功能，也可修复问题，
  不再使用 `preview.n` 作为新版本编号。`0.2` 等分组仍表示产品方向，不要求每次发包完成整组。
  未完成的功能不因版本号提高而自动算作已交付；未签名、本地开发包状态独立标明。
- 每个里程碑允许多个可运行预览，但必须通过本版本的完整旅程才关闭里程碑。
- 已验收的 Screenbox 风格播放器是视觉基线，现有交互保留并按功能另行验收；后续增量扩展，不能推倒重做。
- 播放器验收不等于文件浏览器、传输中心及其他页面已通过视觉验收。
- 文件浏览器已选择 A「清晰 Fluent」：参考 Files，与现有 Screenbox 风格统一；原生代表性切片仍须验收。
- 近期以功能旅程为主，A 方向的明暗主题、清晰度和基本视觉质量仍是当期门槛。
  B「栖卷书房」与 C「影音工作台」保留为后期多风格主题候选，排入 0.8，暂不并行实现。
  明暗模式是同一方向的显示方式，不等于三种不同视觉风格。
- 所有应用窗口使用统一无边框、自绘标题栏，保留必要的原生窗口交互与阴影/圆角。
  Windows 图标保留 Android 品牌矢量，独立放大主体并使用透明圆角背景，适配桌面尺寸。
- 下面的版本归属是交付顺序，不是所有模块必须串行开发的要求。
- 新增、取消或移期功能必须同时修改该表与对应能力状态，保留原因和依赖。
- 验证按真实改动及风险选择，避免每个小版本重复无关全量测试；共享契约、权限、数据与恢复
  保留聚焦回归，候选版继续完成整个目标要求的完整验收。

## 0.1 已有能力与边界

当前已有：临时账号密码/免认证连接、系统网络直连（包括系统 Tailscale 路由）、
目录列表及返回/上级/刷新/取消、五种排序、当前已加载目录的名称过滤、基础详情；
原生图片查看/前后张/缩放；libmpv 原生视频、暂停/seek/音量/静音、全屏、章节、
内封字幕/音轨、本地外挂字幕、按格式开放的字幕样式、自定义倍速、服务器进度与续播；
完整本地媒体文件可通过启动参数离线打开。程序使用 Android 同源品牌图标。

仍没有：持久连接和凭据、服务器搜索、缩略图/网格、新建/改名/复制移动/回收站、
上传下载/任务中心、音频入口、服务器外挂字幕、雪碧图、跨文件选集、HLS 画质切换、
文档编辑/分享/管理等。源分辨率单项显示不是多画质，章节不是选集；当前目录过滤不是
远端递归搜索。服务端续播与字幕/格式组合仍须用实际服务器和样本验收。

## 功能里程碑

历史 0.2.0-preview.1 交付无边框/品牌/主题切片；preview.2 增加 SQLite 连接档案、
DPAPI 保持登录、恢复/退出/遗忘，以及列表/图标网格切换和自适应详情面板。
此批功能改用普通版本号 **0.2.0** 交付，后续使用 `0.2.x` 增量。
网格尚无远端缩略图，名称过滤仍仅覆盖当前已加载目录。服务器搜索、布局持久化及文件写操作
等 0.2 目标继续推进，原生浏览器切片仍待用户验收；版本号不代表该里程碑已关闭。

近期优先级已按用户要求调整：**0.2.1 优先视频预加载和磁盘缓存**，显示真实时间范围、
实际服务器下载速度（MB/s），支持自定义缓存目录和总缓存数据上限（默认 5 GB），

三类缓存共享同一总预算，不能各自占用 5 GB；缓存清理不能触及下载文件或用户目录中的其他数据。

## 最新跨端变化的具体落点

主线快照 `67853b2f` 的增量已核对；这些是对齐要求，不表示 Windows 已实现或已合并主线。

- **0.2 登录恢复**：按认证拒绝、权限拒绝、网络/组网、本地凭据/数据库及未知阶段分类反馈；
  诊断不输出原始私密错误。续期后更新同一 userId 的 claims/用户名/权限再保存与激活。
  对 renew401 的分类保持共享核心严格边界：不把403/503/断流/非法token变成密码恢复，
  不重放操作，已确认成功写入不得丢失。
- **0.4 字幕**：列出已安装系统字体、默认/跟随系统与失效回退；文本字幕可选择画面内或
  包含黑边的播放区域，黑色背景0—100%且默认透明，支持预览/重置/设备保存。
  切区域不改变视频尺寸或字幕字形；ASS/SSA作者样式、位图能力边界继续保留。
- **0.4 队列和轨道**：当前项缩略图/序号/正在播放、滚到当前项；confirmed与pending反馈、
  重名轨道去歧义、分层返回。Android的手机触控锁和标题排法不强行套到桌面播放器。
- **0.5 更新/0.9 门禁**：核对不可变tag/修订、显示版本、资产名和实际包版本，拒绝降级与
  虚构revision；稳定版高于同核心预览。已签名渠道校验发布者/签名，未签名本地预览
  明示状态与固定来源/哈希，不能假装具有可信签名。GitHub仓库身份可忽略大小写，
  tag/资产必须精确，URL不能整体转小写；关于页提供仓库与许可证入口。
- **0.8 设置作用域**：账号安全、本机原生偏好、服务器管理分开；明确全局操作会影响其他用户。
  不复制对原生客户端无效的网页选项，也不因Android删除某页就排除Web仍有效的能力。

## 核心依赖与不变约束

身份/能力/本地数据先于写操作与传输；传输任务和不可变资源身份先于边下边播；
媒体质量选项来自真实服务端 HLS 能力，不能生成假的 720p/1080p 菜单。
扩展接口优先使用已有 server/shared-core 契约，新增行为必须向后兼容并有 Android 回归。
Windows 保持 WinUI 3、Go Host 私有 IPC、libmpv、SQLite/DPAPI 的既定边界。

本地路径和远端 wirePath 分离，目录/文件名不经过 Windows 路径归一化改写远端身份。
Delete 显式使用回收站语义；服务端和本地任务分别管理，取消请求接受不等于取消完成。
所有成功/失败/部分成功/冲突/结果未知必须可解释。后台任务、缓存、历史与租约均绑定账号。

不购买签名、不修改 Android 标识、不自动合并 main、不自动改 NAS 生产状态；
不将原有“首版非目标”永久当成 Web/Android 功能的排除理由。
