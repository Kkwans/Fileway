# 栖卷 Windows 0.6.0

文档与归档（查看类）里程碑；本地未签名预览，供用户人工安装验收。

## 本版新增

- **文本/代码只读查看器**：`text/*` 或 40+ 常见文本/代码扩展且 ≤4 MB 的文件双击进入
  只读查看。内容经缓存租约流式读取并按解码预算收束；编码按 BOM → 严格 UTF-8 →
  GB18030 回退顺序解码并在窗口内如实标注（回退不冒充真实编码）。自动换行切换、
  复制全文；查看器不授予任何写入权限。
- **Markdown 原生渲染**：`.md/.markdown` 默认渲染视图（自研有界子集，不引入
  WebView）：标题、段落、行内粗斜/删除线/行内代码/链接、有序与无序列表、围栏代码
  块、引用块与分隔线；表格等未支持语法退化为预格式文本而不是静默丢弃，图片语法
  折叠为 alt 说明，仅 http(s) 链接可点。渲染与纯文本一键切换，渲染异常自动回退。
- **CSV/TSV 表格视图**：有界 RFC 4180 解析（双引号转义、引号内换行与分隔符、
  ≤500 行/≤60 列并如实标注截断与总行列数；引号未闭合的坏文件保持纯文本不硬解
  析）；分隔符按扩展名与首行统计探测。表头固定加底色，数据行 ListView 虚拟化，
  固定列宽横向滚动。

## 边界

- 查看器全程只读：不创建任务、不写入远端；文本编辑/草稿、PDF/EPUB/CSV 下载后
  编辑、归档包内浏览/解压与本地文件打开保持 0.6.x 后续范围。
- 4 MB 解码预算以诚实错误呈现超大文件，不做分页加载承诺。
