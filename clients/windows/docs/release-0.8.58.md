# 栖卷 Windows 0.8.58

0.8.58 重做「帮助 → 键盘快捷键」：从代码拼装的普通两列表格改为设计系统内的单栏分组键帽布局，12 条快捷键一次可见。

## 本版完成

- 键帽使用 `FwSurfaceRaisedBrush` + 1px `FwStrokeBrush` + 6px 圆角 + 12px 半粗字，浅/深色一致。
- 按“浏览与导航 / 文件与选择”分组；组合键与说明分列对齐，长说明自动换行。
- 滚动区改为 440 高并保持可见滚动条；当前 12 条内容可完整显示，避免用户误以为只有前半部分。
- 两栏键盘面板试排时在默认对话框宽度下右侧说明被裁切，已判定为回归并回退为单栏。
