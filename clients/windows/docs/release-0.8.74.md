# 栖卷 Windows 0.8.74

0.8.74 给文本查看器补空文件状态，并为媒体播放器做 1200×900 复核：空文件不再显示一块空白编辑框，媒体播放器顶/底栏渐变与控件布局正常。

## 本版完成

- 文本查看器新增居中空状态：72px 圆角图标容器（file 图标）、20px“文件为空”标题、13px/20“这个文件没有可显示的内容。”说明。
- 空状态仅在内容长度为 0 且非编辑时显示；点击“编辑”后自动隐藏，保存出内容或取消编辑后按内容重新判断。
- 媒体播放器复核：顶部标题/返回栏已有 `PlayerTopGradient` 暗色渐变，底部控制栏、进度条、音量/字幕/倍速/全屏按钮在 1200×900 与全尺寸窗口下均正常；本版未修改播放器。
- 空文本截图使用真实服务器文件 `empty.txt`（0 B）。
