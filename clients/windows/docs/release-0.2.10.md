# 栖卷 Windows 0.2.10

Windows 11 x64 未签名本地预览，由用户人工验收。

## 托盘与关闭行为

- 复用现有 WinUIEx TrayIcon，应用运行期间显示统一品牌托盘图标；点击恢复主窗口，
  右键提供打开、关闭偏好和退出。
- 默认点击主窗口关闭按钮或 Alt+F4 隐藏主窗口，保留账号、下载/上传和播放会话。
  托盘图标和菜单始终提供重新打开入口，不以隐藏窗口表示退出。
- “工具 → 关闭窗口后保留在托盘”可关闭该行为；托盘右键也可选择关闭窗口时彻底退出。
  偏好保存到当前 Windows 用户，跨版本沿用。
- “文件 → 退出”、托盘退出和安装器退出请求均走完整应用关闭流程，停止传输并释放本地核心，
  不受隐藏偏好影响。托盘初始化失败时不启用隐藏，防止用户找不到仍运行的应用。

## 安装器

- 仅检查当前用户、当前 Windows 会话中位于所选安装目录内的应用/核心；其他目录的
  开发实例或免安装包不再因同名进程阻止安装。
- 发现运行实例后可确认自动正常退出，并等待最多 30 秒；支持隐藏主窗口。
  旧版本使用普通关闭请求，新版本使用明确退出请求。无响应或孤立核心仍提示手动处理，
  不强杀、不忽略仍运行的进程。卸载使用同样的退出流程，范围限于被卸载目录。
- 添加 DPI-aware 和 PerMonitorV2 声明，避免安装向导被系统作为不感知 DPI 的位图整体拉伸。
  实际 150% 和跨显示器外观尚未人工验收。

## 已知问题与交付边界

退出 CFG 崩溃仍未确认根因修复；新增托盘和退出入口不能作为“退出稳定性已通过”的证明。
关闭前服务清理和实际进程终止仍是不同阶段。本批仅构建、生成安装包，不执行测试、
不安装或操作用户正在运行的应用。其他功能沿用 [0.2.9](release-0.2.9.md)。
