# 栖卷 Windows 0.8.37

0.8.37 收尾列表组件：收藏/标签管理、传输中心也接入 `FwListViewItemStyle`，并把收藏空状态拆成标题与说明。

## 本版完成

- 收藏/标签管理页的收藏列表、标签关联资源列表改用自研列表样式：行卡片、悬停/按下底、半透明强调选中底 + 左侧 3px 标记、圆角焦点环。
- 传输中心列表改为以 `FwListViewItemStyle` 为基底：保留批次卡/文件行原有卡片背景，仅新增左侧选中标记与圆角焦点环，避免系统选中底被行内卡片遮挡后完全不可见。
- 收藏空状态按设计契约拆分：20px 标题（“此分组暂无收藏”“暂无标签”“选择标签”“此标签暂无关联资源”等）+ 13px/20 次级说明，不再把整句长文案放在 20px 标题里。
