# 栖卷 Windows 0.8.7

0.8.7 增加“把文件/文件夹拖到文件夹上即移动”的桌面交互（实验性，需真实鼠标验收）。

## 本版完成

- 文件网格/列表启用内部拖拽：选中项可拖到同一目录下的文件夹上，松开后提交服务器移动任务。
- 拖拽期间显示“移动到 <文件夹>”拖拽说明；目标为文件、或拖动项本身是目标文件夹时不接受。
- 移动使用服务器任务（同名冲突停止，不覆盖），完成后沿用 0.8.2 的任务轮询自动刷新当前目录。
- 拖入外部文件上传（0.8.1 已有）保持不变。

## 验证情况

- `DragItemsStarting` 已由自动化确认触发（items=1，Rename/Create 权限均为 true）。
- 自动化鼠标/触摸注入无法触发 OLE 拖放的 Drop 阶段，因此**“松开后实际移动”未完成端到端验证**；需要真实鼠标拖拽确认。若失败，请提供当时是否有“移动到 …”提示与目标高亮。
