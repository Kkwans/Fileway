# TV-owned native test fixtures

All audio/video is a generated test pattern and 440Hz sine, with no third-party film or user data. The 150-second H.264/AAC SDR source is 160x90 at 2fps, tagged BT.709; it proves neither 1080p performance nor HDR. HLS is generated by the actual isolated Fileway backend during native journeys; no static simulated HLS response is used. The audio-only file copies 12 seconds of AAC.

Generate source with FFmpeg lavfi testsrc2=size=160x90:rate=2:duration=150 plus sine=frequency=440:sample_rate=32000:duration=150; libx264 veryfast CRF32, yuv420p, GOP4, AAC24k, faststart, BT.709. H.264 SPS transfer_characteristics=1, colour_primaries=1 and matrix_coefficients=1 are set explicitly, alongside the MP4 colour tags. Decoded source pixels are unchanged by this metadata operation. Captions are project-owned text at 1-10 and 120-140 seconds.

These fixtures are used only by instrumentation APKs.
