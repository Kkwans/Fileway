# 栖卷 · Fileway Android 1.2.1

- 修复播放器自定义倍速、长按倍速等输入面板的键盘避让。输入窗口自行适配键盘占用区域，表单在空间不足时可滚动；倍速预设的保存区域不再挤占输入列表。共享文件操作、编辑和确认窗口同步处理键盘边界，保留原生局部模糊与视频 Surface。
- 文件类型筛选新增“压缩包”，文件页和搜索页共享 ZIP、RAR、7Z、TAR、GZ 及常见复合后缀识别；不扩大服务端预览或解压能力。
- 搜索结果增加名称、修改时间、大小排序，复用文件列表规则。对全部已收到的结果排序，搜索中继续接收新结果；保留上限、超时、取消等提示，不把部分结果冒充完整结果。排序不清空选择或改变原始路径。
- 缩小“离开应用时自动画中画”的图标、字体和开关外观，与相邻设置行对齐；整行仍保留足够点击范围，设置保存逻辑不变。
- 播放列表和“接下来”统一文件名展示：使用实际可用宽度和逐行断行，允许在英文元数据分隔符处换行，改善中文片名被后缀挤断的情况。仅改变显示，无障碍名称、真实文件名与资源身份保持原样。

正式版 **1.2.1 / versionCode 45**，Android 10及以上，包含 arm64-v8a、x86_64。沿用原包名、签名、本机数据，服务端 API 和数据库结构不变。

本轮按用户确认范围执行编译、定向规则检查和发布校验，不追加手机验收。键盘与换行的最终真机观感未在本轮额外验收，不将规则测试或编译结果视为设备视觉验收。
